# 监视页导航图标

七张透明 PNG 使用内置 image_gen 生成，分别用于 GIS、工艺画面、数据总览、历史报表、历史数据、站点菜单和设备台账。台账沿用同系列蓝青玻璃圆盘、双发光圆环与立体档案/齿轮，替代 v16 矢量图标。原始生成字节保留；完整提示词见 [prompts.json](prompts.json)。

每个功能只有一张图片。`MonitorHeader` / `MonitorStationList` 通过 Flutter 的透明度、渐变、阴影、文字和边线实现选中、未选中与悬停状态，过渡为180ms；遵循系统减少动画设置。背景星点为静态绘制，不使用循环动画。

本目录属于界面外观资源，不加入工艺设备素材目录，也不携带实时状态或点位绑定。
