# Original example symbols

The four static SVGs in this directory were drawn for Universal HMI to recreate
the user's heating-station reference as editable equipment. They are repository
source, covered by the repository's MIT license. They are not FUXA assets and
are not screenshots of operating equipment. Colors are illustrative; operational
status always comes from explicitly bound points and their quality.

The reference photo itself is not bundled. The example blueprint is in
`../templates/heating-station.json`; every real-time binding starts empty.
