# 设备图片失败重试

## 修复范围

设备照片下载失败和图片字节解码失败两个分支，原重试事件把 Future 赋值表达式直接作为 setState 回调返回值，会触发 Flutter 调试断言。改为同步块内保存新请求 Future；请求契约、缓存键、权限、图片数据与预览行为不变，不引入轮询或自动重试。

## 确定性回归

`app/test/equipment_photo_retry_test.dart` 使用合成 PNG 与受控 API：

- 首次网络失败 → 手动重试 → 图片恢复 → 打开/关闭预览。
- 首次返回非图片字节 → 解码失败 → 手动重试 → 图片恢复与预览。
- 重试请求未完成即卸载宿主，随后晚响应完成，不触发已卸载状态更新。

同三项测试在修复前全部因 `setState() callback argument returned a Future` 失败，修复后全部通过。测试合成资料不代表现场图片、真实浏览器或原生 DPI 验收。
