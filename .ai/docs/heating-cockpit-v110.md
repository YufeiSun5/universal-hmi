# 驾驶舱天气设置及缺数修订 v110

开发端「运行与历史 → 驾驶舱配置 → 天气预报」填写和风 API Host、API KEY 和经纬度，保存后后台重新取数。已保存的密钥可留空沿用。配置接口返回域名和密钥设置状态。密钥以工程加密密钥封存，天气账号信息独立于驾驶舱 JSON，旧版导出的 JSON 可继续导入。

站区工况使用点位工程单位，点位单位为空时沿用总览列的单位。供热功率继续由后端换算 MW，已配置计量行去重汇总并保留缺数。整站小时读取已约定的有效状态。

耗热排行左栏为数据库返回的今日累计。右栏比较今天和昨天从 00:00 到同一整点的完全结束小时，栏标题标注整点。在 15:50 读取时，两天都比较 00:00–15:00。日合计仍要求相应整站数据齐全。
