2026-10-29，PUBLIC-REMOTE 实现完成。用户确认现场电脑、固定公网 IP、无域名、自签证书，接受浏览器警告；IP 后填。6.1 Sol 实施后端、打包与可选服务宿主，6.1 Terra 实施客户端，主代理负责方案、代码审查、退回修复和最终验收。产品母本为 [agent.md](../../agent.md)，使用方法见[配置指南](public-remote-guide.md)。本批没有开放真实公网。

## 交付与契约

- `dist/Universal-HMI-PublicRemote-20261029` 为本次独立 Windows/Web 目录包；不是新安装 EXE。源码摘要 `e2a8499a12ff237c862ae8cfd7b2d78d2f649ab7ad64714fffda08ea33fbd99c`；后端 SHA256 `181d0a48531eb1f1e13541a2118784b47a204a9b0acebd3a5441aa7d36852d64`。
- 同一个 Go 后端和工程数据库保留回环 HTTP，按配置增加 HTTPS；默认禁用、origin 为空。证书工具生成带 IP SAN 的自签叶证书，私钥不放入 Web 或交付给客户端。启用、换地址、换证均需明确重启；启动器核对配置摘要，不复用配置不一致的后台。
- 原有业务 API、实时订阅、文件上传下载、设备图片使用统一客户端传输。原生客户端导入公开 PEM，核对叶证书 SHA256、主机名与有效期，不修改操作系统信任。GIS 通过受限回环代理和 WebView2 导航限制访问远端静态内容。
- 远程入口使用 `--remote-only`，无效/空配置进入设置，不启动本机 PG/后台；本机工程入口使用 `--local-only`，不受保存的远程选择影响。身份以规范工程地址及 developer/runtime 角色区分。设置更新须保存后退出重开，不在带草稿的会话中热切换。
- 公网仍遵守原身份、MFA、角色、资源范围和受控写入服务；未降低授权要求。可选 [Windows 服务宿主](windows-service-host.md)已提供，但本轮未在真实 SCM 安装或启动。

1. 固定 Go 1.24.7：最终 `go test ./...`、`go vet ./...` 通过。Flutter 3.35.4：全量 242 项测试及 analyze 通过；最后仅连接页主题调整后，4 项连接测试和 analyze 再次通过。
2. Windows/Web release 构建与源码前后摘要通过。首次封装发现 Windows 输出目录遗留旧后端，来源校验正确拒绝；保留旧输出，清空目标输出重新构建 Windows 后再封装，通过全部产物和双端来源一致性检查。没有修改来源记录绕过检查。
3. 最终包内后端在独立 SQLite、回环 HTTP + 实际 TLS 上通过首次建号、登录/MFA、授权读取、图片素材上传读回、画面保存读回、实际值 SSE、20 次带 body 的 401/403 拒绝、本机部署端点限制及双监听正常退出。见[最终包测试](evidence/20261029-public-remote/package-tls-smoke.json)和[回归摘要](evidence/20261029-public-remote/smoke-summary.json)。没有连接原工程或现场设备执行写入。
4. 主代理审查复现早期 TLS 拒绝请求偶发断连，退回修复为至多 64 KiB / 一秒的有界读取；不完整、大或流式 body 关闭连接并保持立即截止时间。最终真实 TLS 回归覆盖声明 1 KiB/128 KiB、仅发一个字节，在三秒内获得完整 403；不使用写请求重试掩盖问题。
5. Flutter 隔离 TLS 覆盖正确证书、错误主机、过期、替换证书及同 CA 不同叶证书；连接设置覆盖空地址保存、远程配置缺失不启后端及本机入口保留远程选择。GIS 代理覆盖路径/方法/重定向限制。远程启动器 2 项测试、服务安装模拟权限策略通过。
6. 最终 Windows 实包连接设置页实际查看通过，未保存用户配置。隔离原生测试覆盖并发/顺序重复启动、双角色并存、跨工程独立、最小化恢复、关闭收起与重开、崩溃恢复；4 次正常菜单退出返回 0，另一端与共享 API 保持运行。见[桌面结果](evidence/20261029-public-remote/native-review.json)。这些窗口测试使用回环测试工程，不声称公网双端登录已实测。
