# 外部报表结果列配置 v64

用户要求修复所有外部数据报表及热量结算的列配置、完成完整测试并交付安装包。本批只调整 Flutter 外数据与共享报表展示，沿用 externaldata 的画面保存、revision、权限及查询接口，不修改现场数据库、价格或业务计算。

## 原因与修复

- 原“显示列配置”编辑固定字段类别，统计报表又按实际测点横向展开，二者列数和粒度不同。开发端统一从“报表样式”编辑当前展开后的结果列，展示总列数和可见列数，按指标组区分同名字段。
- 样式编辑器原先累计所有历史表结构，可能打开旧查询或查询前的占位列。现在只登记当前挂载的表；动态列尚未查询时提示先查询。同期汇总及结算有已知的独立字段，结算仍为五个业务字段。自定义过程字段变化后的恢复入口保留。
- 动态报表原先按整张表字段列表的摘要存布局，增减测点会使样式失效。统计按查询方式、历史按报表种类保存；字段使用原测点/统计字段身份，过滤和列数变化不再错配。旧的当前结构样式按字段迁移，显式保存后替换对应旧键；其他站区的列设置保留。
- 统计报表原先先按页面默认小数位舍入，再套列小数位。现在列设置直接格式化原始十进制字符串，范围两端分别格式化；NULL、有效零及长 decimal 保留。CSV按同一可见列和顺序导出原始精度，结算标题行不参与表头匹配。
- 样式保存保留当前查询结果；统一样式宿主每5秒按已有画面目录revision读取配置，运行端无需重新执行数据库查询。报警运行入口接入相同样式；月报/采暖季等派生页面保存后仍停留原页面。原有独立查询组件保留其原配置刷新路径，宿主内取消重复刷新。
- 小窗口配置弹窗支持滚动，保存/取消仍可达；不允许将当前结果全部隐藏。
