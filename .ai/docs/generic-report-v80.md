# v80 通用报表历史绑定与区域迁移

2026-11-12。产品要求见 [agent.md](../../agent.md)，分层合同见 [architecture.md](architecture.md)。本页记录本地实现与验证；安装包和最终CI状态在交付时补齐。

## 使用

开发端打开报表，选中单格、一列或一行，点击“数据绑定”。选择历史来源、站区、测点、取值方式及时间，先预览每格的目标时间、实际采样和结果，再确认保存。已有绑定可以修改、复制为新绑定或移除。

- 取值方式：指定时刻表底、区间最小/最大/平均值、数据库完整日用量、数据库已结算小计。原始历史与日结算来源分开；完整日用量缺失不回退到小计或表底差。
- 日期可使用文字日期、`{year}` / `{nextyear}` 年度参数，或引用表内日期/Excel日期/日期公式。引用可随行列移动，也可固定一个查询日期单元格，再按间隔天数铺开；支持日期偏移、取数时间、0–180分钟容差和不超过31天的区间。
- 每组绑定是一行或一列，最多366格；每表最多64组。不同站点可复制绑定后调整区域、站区和测点。当前采用既有外部历史模块的标准历史/日报来源，不开放任意SQL。
- 自动取数格只读；刷新只更新绑定区域。缺测和坏质量保留空值，有效0保持。未到的目标时间不查询，但仍校验来源、测点和单位。
- 保存绑定只影响当前年度，其他年度不被重写。需要复用配置时导出整表配置，再新建独立报表。原三份季节模板保留既有行布局；任意日期范围可在独立Excel页面中配置，当前没有增加自动插删季节行的专用设置。

热表旧绑定兼容转换为通用绑定，保持原零点口径。修改各列时间后，共用时间列显示实际一致时间；各列不同时显示“按列绑定”，具体时间见绑定预览。移除绑定后对应表底格可人工填写。修改过的通用绑定不能被旧热量同步接口覆盖。

## 整表与局部导入导出

“导出整表 / 局部”支持Excel和 `.hmi-report.json`。Excel用于数据交付，配置文件同时保存公式、格式、绑定及原稿；不包含数据库密码。局部Excel保留原单元格坐标，不携带区域外数据。

导入支持选择Excel工作表/来源区域，或读取报表配置文件。可以新建整表副本，也可以指定当前表落点，选择全部、仅格式、仅公式、仅绑定或仅数据。先预览覆盖数量、区域外公式/日期引用及行列尺寸影响，再确认应用。合并格被截断、来源测点失效、目标有租约或版本过期会拒绝整笔操作。

相对引用随位置移动，绝对引用、字符串和名称保持。选区之外的人工值保持；原稿保留边框、打印/分页等原生设置，复用时不会把原稿未使用的样式边界误当作可编辑表格尺寸。支持单矩形条件格式的局部裁切和移动；复杂多区域条件格式会明确拒绝局部改写，可使用整表副本。在线表格仍受FortuneSheet支持范围限制，不能把Excel原稿完整导出等同于所有Excel特性都能在线编辑。

“配置历史”列出绑定或导入前的版本。具备开发及报表恢复权限的用户可恢复整张表的配置、原稿和人工内容；恢复前保留当前版本，自动数据清空后按恢复的规则重取。普通“历史记录”继续按原权限恢复人工内容。
