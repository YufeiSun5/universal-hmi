# GIS 地图显示设置 v106

开发态打开 GIS 画面，在右侧「地图显示设置」配置倍率、站标图标和大小。倍率范围 0.5 至 2.5，默认 1×。站标可选换热站、定位针和圆点，支持小（48 px）、中（64 px）、大（80 px）三档，默认小号。确认后可先预览，再点「保存画面」。运行端重新打开地图时读取已保存设置，开场落地、默认视角和巡展停靠使用同一尺度。手动平移和滚轮缩放属于本次浏览会话。

同一经纬度的站标保留各自数据。悬浮时宽屏将各站卡片分列到站标左右，空间不足时上下排列。分区数据和导出按各站独立处理。配置合同见[架构](architecture.md#gis浮窗变量引用2026-10-26)。

覆盖升级前备份完整工程。若保存了显示设置后需要回退到旧版，使用升级前的工程备份，旧版无法读取含新字段的 GIS 文档。
