# v35 历史统计与独立能耗交付

产品要求见 [agent.md](../../agent.md)，唯一任务见 [AI_BOARD.md](../../AI_BOARD.md)，技术契约见 [architecture.md](architecture.md#历史统计与独立能耗2026-11-04v35)。

本批基于 v34 证书和轻量登录实现，历史目录包含历史查询、小时报、日报；能耗管理独立入口，复用现有KIOHistory连接并单独授权。现场需由开发端创建相应画面、复用已有连接并按账号授权，不自动修改现场配置。

参考用户提供《庄河供热水电热模块_平台开发对接说明》V1.0（2026-11-04）和庄河HTML/pages/report-center。真实SQL验证使用原六参数过程、隔离SQL Server 2019及合成数据，不连接生产数据库。数据库负责差额、范围、整站口径和状态；NULL不补零，站区不自行汇总，去年同期对比留后续。

## 使用与显示维护

开发态「外数据 → 添加查询画面」选择历史查询、小时报、日报或能耗管理，并复用现有 KIOHistory 数据源。每个画面通过账号的外部画面范围单独授权；已有小时报身份和授权保留。数据库必须已提供对应的六参数统计过程，平台不执行生产数据库升级脚本。

在开发态打开小时报、日报或能耗画面，点击「显示列配置」即可修改列名、显隐和顺序，支持配置导入导出；点击「保存配置」后生效。运行端没有维护按钮，已打开页面约5秒内同步列配置，无需重新查询数据库。维护状态、采样时间、统计进度及核查小计默认隐藏；站区核数仅在开发态提供。隐藏状态不改变数据库有效性判断，缺数仍显示“—”，有效零显示0。CSV只导出可见列，遵循配置列名和顺序，数值保留数据库精度。
