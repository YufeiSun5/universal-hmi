## 适用范围与隔离边界

本规范适用于领导日常使用的普通运行页面：工艺画面周边目录、设备台账、数据总览、历史报表、历史数据、外数据。整体方向为中性浅灰、清晰分层、紧凑桌面控件，避免全黑内容区和网页式大卡片。

**不影响 GIS 首屏及类似驾驶舱。** 地图、地球飞入、自动巡展、月亮/卫星/流星、站标和浮窗属于独立展示体系，保留其现有视觉、透明顶部叠加、镜头和交互。不得把本规范的浅色底、目录、标题条或内容边框套进驾驶舱，也不得通过修改全局主题间接改变它们。

**顶部使用原 MonitorHeader，只按最新要求调整普通页配色。** 完整标题“智慧供热集中监控系统”、生成图标造型、时钟、原76/112高度、布局、字号、间距及账号操作保持。普通页面改为浅灰蓝 `#DCE3E8` 背景、低饱和灰蓝图标、深色文字；选中项显示原彩色图标，不铺选中背景，仅保留下划线，未选中图标仍为灰蓝；去除星点、文字/图标光晕和发光底线，保留简洁选中线。直接使用原透明PNG着色，不重绘或替换图标。GIS继续使用原透明顶部、原图标颜色和原选中效果。此前错误替代的RuntimeHeader已删除；不能只比较组件文件不变而忽略实际调用。此条取代早期普通顶部颜色必须保持的要求。

登录页面、开发工作台和工艺编辑器保留各自已建立的规则。本轮不引入真实系统 Mica、模糊或透明窗口；浅灰层次只借鉴桌面材质观感，不声称原生 Mica 已实现。

## 视觉语言

参考 Figma 桌面软件的紧凑组织、细分隔线与层次，参考 Windows 桌面控件的清晰选中、焦点和悬停反馈。控件应看起来并用起来像桌面软件。

| 用途 | 颜色/尺度 | 约束 |
| --- | --- | --- |
| 普通工作区 | `#E9ECEF` | 中性浅灰 |
| 默认供热工艺背景 | 钢灰静态柔和渐变 | 增加设备层次，文字和数值区保持清晰；不加动态、摄影纹理或光晕 |
| 工艺目录 | `#E2E6E9` | 与内容区有轻微层差，不做黑色侧栏 |
| 工艺内容标题区 | `#E8ECEF` | 延续当前尺寸，不增大标题或另加工具条 |
| 正文 / 次要文字 | `#293D4B` / `#647581` | 深灰蓝，浅底上清晰可读 |
| 分隔线 | `#C4CDD4` | 细线；避免厚框与密集装饰网格 |
| 选中底 / 强调 | `#CBD4DC` / `#465F71` | 石墨灰选中与深色图标文字；目录仅当前画面铺底，父分组以文字/图标标识，不用双层蓝色底块 |
| 阅读和输入表面 | 近白或 `#F1F3F5` | 与灰色工作区分层；圆角以 4–8 px 为主 |
| 字体 | 正文约 12–14 px，标题约 16–21 px | 延续项目中文字体；字号随内容层级，不整体放大 |

表格、筛选和目录以操作效率为先。保留鼠标、滚轮、键盘焦点、快捷键、右键和窄窗入口；小窗口可用抽屉或滚动，不裁掉操作。状态同时有文字与图标，不仅依赖颜色。普通页面统一的是外壳和控件语言，不强行把不同业务组织成同一套卡片。

运行端台账使用连续目录与内容面板，汇总数字为一行简洁计数，列表行高60px；不使用大统计卡片和外层圆角容器。数据、报表等阅读面板保留12px边距和4px小圆角。台账开发维护模式沿用原表单流程。

## 工艺画面与数据

普通运行页的工艺目录、站点范围、设备站区和外数据目录使用共享桌面侧栏：宽248px、标题38px、搜索32px、目录行约32–34px，2px小圆角与细分隔线；减少卡片和多层圆角容器。当前画面使用浅石墨底，父分组只以文字和图标标识。工艺目录在切图时只更新选中项，保持原树、滚动位置、搜索和折叠状态；普通页面间切换后返回仍保留。窄窗口保持原抽屉入口与可滚动内容，GIS不套用该侧栏。

设备图片、管线走向、坐标尺寸、连接、稳定变量 ID、单位和数值逻辑保持；供回水管线及有业务含义的颜色不做全局滤镜。

内置供热模板原深蓝背景可在运行展示时映射为浅灰，同时将其默认青色文字、黄色数值和青色数值框映射为可读的深色文字和细灰框。映射只处理已识别的模板默认配色，不保存回源文档，不改变修订号、公共布局或站点绑定；用户自行修改的背景与非默认语义颜色保持。开发编辑器继续显示保存的文档样式。后续如增加持久化主题选择，应单独设计显式配置，不借换肤静默改写图纸。

未绑定、离线、坏质量、未知结果不能被浅色主题隐藏或伪造成正常值。不增加设备操作、权限或后台业务逻辑。

## 实现与检查

普通内容 token 位于 `app/lib/features/process/runtime_chrome.dart` 的 RuntimeStyle/ProcessStyle，工艺运行配色适配位于 `presentation.dart`。所有运行页调用原MonitorHeader，以showGis区分普通页配色与驾驶舱原色；已删除错误的RuntimeHeader替代实现。GIS资源独立，禁止为浅色内容改变地图主题。

验收需要实际普通页面及大小窗口截图，确认目录搜索、切图、页面切换与状态可读；检查顶部造型和布局保留、普通页配色符合本规范，GIS 透明导航及原色保持。运行配色检查原文档不变、管线和绑定不变、自定义背景保留。编译和测试结果见[本批验证](runtime-light-verification.md)；效果图不等于运行验收，Web 截图不等于原生 DPI/多屏验收。

2026-10-28 追加：工艺运行区背景使用静态钢灰柔光层次，背景贯穿整个视口，缩放时无矩形接缝。只替换已识别内置模板的运行背景；保存的图纸、管线、变量与自定义背景保持。顶部彩色选中图标不恢复额外发光或选中底块。实际验证见[本批记录](process-surface-verification.md)。
