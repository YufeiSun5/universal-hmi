# 内网开发端与运行端同时登录、供回水范围连线

同一浏览器的普通 Web 开发入口和运行入口分别保存会话。同一主机不同监听端口的 Web 入口也能独立登录。升级后每个入口第一次使用时登录一次。后端按原监听配置和账号权限决定可用功能。

重点曲线在同站区、同一小时的供水和回水范围柱之间画细灰色竖虚线，温度和压力各自配对。两侧均可见且有间隔时显示。范围柱采用淡色填充和轻微圆角，悬浮读数采用等宽数字，沿用原有数据、单位和选中标注。

## 本地验证

- 旧 Web 会话回归在相同地址双入口、同主机双端口上均复现第二次登录覆盖第一次。修复后对调登录顺序，刷新、错误 CSRF 拒绝和单独退出通过。
- Chromium 使用同一浏览器配置、两个标签页、同一隔离账号，在实际内网 HTTP 开发入口从登录表单分别进入开发工作台与运行界面。两端刷新、心跳及 gRPC-Web 实时订阅均成功，退出开发端后运行端刷新仍保留原会话。
- Node 图表测试 11 项。Chromium 按合成小时报检查了连线的数量及缺失小时、图例显隐、缩放定位、窄窗适配、实际选中范围柱显示两个极值。
- Go 全量测试及 vet 通过。首次全量中，既有设备维护测试的随机 CSR 请求触发防护规则返回 403，该测试连续三轮复验通过，随后全量通过。Flutter analyze 通过，完整测试 822 项通过、2 项既有跳过。
- 源码 `e5b67d5a`，含 v106 GIS 显示设置。Windows 与 Web 最终构建使用相同源码清单。现场尚未部署。

在隔离目录以最终 EXE 覆盖 v106，停止状态下对比工程文件摘要一致。逐项校验 6729 个应用文件、3154 个 PostgreSQL 文件。启动包内服务后原账号可用，反向退出运行端后开发端仍保持原会话。安装包 SHA256 为 `b00ef1b6f3a9ff55fb1050675385000b3b1503f02125d23a1f74dd3f557235a5`，交付到 Downloads 的「Web登录与重点曲线完整包_v107_20261118」。
