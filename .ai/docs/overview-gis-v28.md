# 庄河数据总览及 GIS 站点批量交换 v28

在安卓底部进入「总览」默认显示单站纵向列表。选择站区后按配置顺序显示左侧指标和右侧读数，每行最小高度32逻辑像素，名称与数值允许换行。时间取当前站绑定变量的最近源时间。右上角切换完整表格，保留筛选。GIS仍是启动首页，桌面使用原有总览表格。

## 总览资料与操作

在开发态打开「配置总览」，点击导入图标并选择本地交付目录中的「庄河总览配置.json」。先勾选站区，再检查站点归属、绑定及变更数量。整表替换会移除草稿中未选行；列定义相同时可选择合并，保留其他行与原室外温度。确认后可调整站点行和变量，最后点击「保存总览」。导出包含所选站区、完整列定义及室外温度。筛选改变时保留选择。

本批离线模板按 KS 脚本 SHA256 edbb6f5022878bbc0e78938a09499ba8de260c0db534b02ec0e5fe72537e10c0 核对实际映射，使用 energy-report 的 displayColumns 展示顺序和站点目录。每站37个传输位置映射为31个显示指标。961个指标格中，856个有效采集引用、105个原空槽；独立表头另有1个引用，合计688个不同KIO路径。张屯使用正向有功电能。映射来自最新 XML IOAccess 与 KIO CSV 的明确对应；文件保存来源与路径，实际导入按当前工程唯一匹配。冲突或缺少的模板点在预览中列出并留空。台账、工艺画面与变量定义均不属于该文件。

## GIS 站点

在开发态打开 GIS 画面，使用「地图站点」栏的导入、导出图标。站点列表 JSON 包含坐标、名称、目标工艺画面、公共数据、分区和绑定。导入显示新增、按ID更新及冲突；缺失变量、目标画面不可用、与现有站点同名异ID的条目不能勾选。确认合并只改草稿，「保存画面」才持久化。编辑单站时仍可单独交换指定配置部分。

## 验证范围
