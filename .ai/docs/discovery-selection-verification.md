# 扫描跨页选择与按钮 · 2026-10-28

用户要求扫描添加变量不限当前页，常用通配符简单可用，按钮简洁且美观。产品母本为 [agent.md](../../agent.md)，契约见[架构](architecture.md)。

## 实现

- Go扫描目录支持普通关键字包含查询、`*`任意长度、`?`单个Unicode字符、英文/中文逗号及换行分隔OR条件；其他字符按字面匹配，不开放正则。保持来源作用域、256字节查询、500项分页和20000项目录上限。
- 目录返回稳定选择摘要；身份、类型、已添加映射改变会使跨页全选失败，数值更新不会。前端完整取回后一次替换选择，失败/取消保留原选择；翻页保留勾选及名称/类型修改，切来源/改筛选重置。
- 输入通配符自动跨页全选，普通关键字用“全选匹配项”。已添加、未知/冲突类型跳过并显示数量。保存仍使用后端原子批量创建，保存与应用分开，不接触设备控制。
- 新`shared/button_styles.dart`统一主/次/辅助按钮外观和悬停、按下、键盘焦点。采用稳定WidgetState映射避免每次刷新都被识别为新主题；完整测试发现过KP等待页面被反复主题动画影响的问题，已改正样式等价性，原测试断言保持。
