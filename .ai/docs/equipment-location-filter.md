# 设备台账位置组合过滤

## 范围

- 独立安装位置文本包含过滤，与站区、小站、类别、关键词取交集。
- 宽窗保留站区、小站与逐项条件标签；窄窗通过“筛选(n)”进入条件表单，主列表保留搜索、单行摘要及一键清空。切站清空小站。
- 原自由文本位置、档案身份、权限、排序及默认查询保持；不做结构化位置迁移，不新增复杂布尔查询语言。
- 未指定站区的小站名称过滤可跨已授权站区匹配同名小站；这是名称条件，不是全局唯一位置。

## 验证

- Go：位置大小写/中文包含、AND组合、过滤后分页、跨站授权、空位置旧档案、无写入副作用及HTTP参数传递。
- Flutter：位置/站区/小站/类别/关键词组合、切站重置、清空、迟到响应、390宽长条件与现有台账回归。
- 最终命令与结果在对应PR记录；真实原生多DPI与生产现场不由widget测试代替。

### 窄屏内容优先

- 小于600宽时，仅常驻关键词、筛选条件数量与单行省略摘要；不让五个筛选框和标签占满列表。统计同步简化为单行，390×600可直接看到设备与列表分页。
- 条件表单维护独立草稿：取消、Back或点击外部不应用；“重置条件”只改草稿，点击“应用”才一次提交位置/站区/小站/类别。主界面的清空同时清除关键词。
- 断点切换保留已生效条件；对话框反向过渡完成后释放临时控制器。窄屏键盘挤压时表单可滚动，底部动作保持可达。
