# 设备台账位置组合过滤

## 范围

- 独立安装位置文本包含过滤，与站区、小站、类别、关键词取交集。
- 窄窗保留站区、小站选择；条件可单独移除或全部清空，切站清空小站。
- 原自由文本位置、档案身份、权限、排序及默认查询保持；不做结构化位置迁移，不新增复杂布尔查询语言。
- 未指定站区的小站名称过滤可跨已授权站区匹配同名小站；这是名称条件，不是全局唯一位置。

## 验证

- Go：位置大小写/中文包含、AND组合、过滤后分页、跨站授权、空位置旧档案、无写入副作用及HTTP参数传递。
- Flutter：位置/站区/小站/类别/关键词组合、切站重置、清空、迟到响应、390宽长条件与现有台账回归。
- 最终命令与结果在对应PR记录；真实原生多DPI与生产现场不由widget测试代替。
