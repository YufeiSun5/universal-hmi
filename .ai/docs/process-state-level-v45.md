# 设备状态灯、比例柱与能耗目录 v45

本批按 [产品母本](../../agent.md) 完成三个相关交互修订：泵/阀图标内的简单彩色反馈灯、可复用的上下限比例柱、能耗页面直接点选的左侧目录。技术语义只维护在 [架构合同](architecture.md)，本页记录验证和交付。

## 行为

- 在开发态选中设备图标，点击“状态灯设置”，选择泵或阀门预设、确认两个状态值及颜色，再绑定真实反馈点并保存。状态灯叠加于图标内容中心，随设备移动/缩放；原设备造型保持，无动画。匹配值默认绿/红，断线、陈旧、坏质量和未匹配值为灰色未知。
- 工具栏新增“比例柱 / 液位”，绑定数值点，在“设置比例柱量程”填写0%下限和100%上限。百分比=(工程值−下限)/(上限−下限)，柱体限定0–100%，超范围保留真实百分比与越界提示。有效零照常显示，未知不补零。仅为画面显示，不改采集换算、历史或现场控制。
- 能耗与同期对比统一使用可直接点选的左目录，桌面和手机均移除页面下拉框。目录可搜索/收起/展开，保留原手机底栏及当前查询。查询条件里的站点下拉框继续用于筛选。
- 现有画面不猜测状态反馈或液位量程；需在开发态配置后使用。公共模板、实例、复制和导入导出保留显示规则，绑定沿用已有授权与身份语义。
