# v81 当前日表底与加载显示

2026-11-13。用户明确要求时间显示00:00，当天尚未结束也显示最新实时表底，并在正在取数的空白格中显示加载状态。产品母本为[agent.md](../../agent.md)，技术归属见[architecture.md](architecture.md)。

## 行为

- 热表时间列原24:00显示改为00:00，日期仍为用量发生日，正式期末仍取次日零点；期初日期、公式、人工内容和已取表底保持。旧年度显示更新前保留检查点，不清空原有数据，重复打开不重复升级。
- 当前未结束时段读取同一已配置历史来源、同一站区测点在本期开始至当前服务器时间内的最后样本。有效零保留；最新样本坏质量或NULL则空白，不回退较早好值，不读未来样本。
- 原热表兼容绑定默认开启本期最新值。通用“指定时刻表底”绑定可通过“未到取数时间时，显示最新表底”开关启停；日结算、最小/最大/平均等取值模式不使用此临时值。
- 临时表底显示`*`，页面提示实际采样时间、尚未结算，以及日/月/季合计包含暂计值。当前时段每分钟刷新；完整历史沿用五分钟刷新，也可点击“刷新数据”。
- 正式期末到达后，下次分钟刷新会重新读取正式边界并替换前一时段临时值；查询失败时原临时值继续保留标记，不把它直接改成正式数据。
- 实际正在查询且尚无值的目标格显示“加载中…”。已有数值刷新时保持可见；未来日期不显示加载。结束或失败后移除加载文字，缺测保持空白。切换报表后的迟到响应和错误不会污染新报表。
- 加载文字和星号只写前端显示缓存，不进入值、公式、撤销、编辑租约或保存。整表及局部Excel仍导出数字，临时表底增加包含采样时间和未结算说明的批注；重复导出/复用原稿会清理过期的自动批注，原有人工批注保留。

“最新”指历史源中当前时段最后一个已落库样本，采集/入库延迟以实际采样时间为准；不承诺现场采样或数据库的更新频率。未更改现场数据库、18153或用户工程配置。
