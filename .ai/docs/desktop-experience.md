# PC 优先的现代工作空间

需求来源：[agent.md](../../agent.md)。下表区分已实现、自动验证与仍待人工验收，不以框架名声称完成全部桌面品质。

## 已实现布局

参考 VS Code 的活动栏、工程树、命令与状态栏，参考 Figma 的中央内容与属性区。使用自有深浅色 token、13 px 正文、35 px 数据行、细边框与紧凑工具栏。

app/lib/main.dart 编排六个工作区；features/editors.dart 提供点位、来源、规则及文件映射编辑；features/trend.dart 绘制图表；shared/table.dart 实现虚拟列表、固定表头、水平滚动、列宽、选中与右键；platform 适配原生文件对话框、浏览器下载及本地 Go 启动。

工程树与属性面板可拖动并记忆宽度，小窗口收起属性区；顶部工具栏横向可滚动。Ctrl+P/N/F/Enter 对应命令、添加、搜索和应用。点位保存与应用明确区分，质量/未知/离线/错误使用文字和颜色共同显示。导入历史目录计入工程树，不生成虚假采集点。

实时图表支持多曲线、质量间隙、滚轮缩放、拖动平移和悬停；默认比较同单位数据。历史图表只对应当前页；统计和导出对应完整筛选查询，分页边界冻结。第一版没有历史全范围降采样及游标与表格双向联动。
