## 2026-10-10 KP 嵌入会话

同一 Web 构建通过 `/kp/` 进入 KP 模式，成功接入后复用现有工作区和角色；未接入、离线暂停、退出提交/等待、过期/关闭使用简短状态页，入口不另要求平台密码。退出发起即退役整个导航和私有草稿/弹窗，失败提供重试退出，等待状态不恢复工作区；KP 真正返回登录页仍由 KP 容器/LogOff 执行。此 UI 不增加现场控制入口，也不把共享业务工程称为逐用户数据隔离。接口和测试范围见 [KP 合同](kp-bridge.md)。

## 当前实现位置与交互合同

以下是源码定位与待验合同，不单凭文件存在判定交互通过：

- `app/lib/main.dart` 组织桌面壳、公共/站点导航、运行总览、监视、历史、设置及停靠区；`features/workspace_session.dart` 保存独立站点会话状态
- `features/operational_dashboard.dart` 提供紧凑运行面板和基于真实样本的小趋势；`features/history_summary.dart` 仅汇总显式加载页，并保留冻结单位、排除无效数值
- `features/variable_matrix.dart` 通过 `SliverChildBuilderDelegate` 按视口创建格；默认紧凑/可切舒适，源时间以提示显示；正常/坏质量/陈旧用文字、图标与边色共同表达
- `shared/table.dart` 提供虚拟行、固定表头、横向滚动、列调整、选中和右键；`features/trend.dart` 承载趋势交互；`features/editors.dart` 承载配置/映射表单
- `features/write_inspector.dart` 根据 Go 返回的真实能力展示类型输入与结果；UI 不重做 Go 的换算、权限、协议或业务规则
- `shared/theme.dart` 使用统一蓝灰浅色 token、紧凑 11–13 px 文本、细边框、小圆角和清晰焦点；状态必须同时有文字，不能只靠颜色
- `platform/` 适配原生文件选择、Web 文件交互、Go sidecar 探测与所有权；桌面关闭不能误杀已存在的独立服务

保持 `Ctrl+P/N/F/Enter` 的命令/添加/搜索/应用入口；键盘、右键、面板拖动、滚轮、焦点恢复和窗口生命周期都需在真 runner 中检查，不能只测 Web 或 widget。小窗口收起/压缩面板时仍须保留任务入口和错误信息，不以裁切或横向溢出掩盖布局问题。

点击变量打开写面板时，区分布尔、整数工程步长、浮点、字符串/虚拟/只读或协议不支持的状态。最终动作仍由 Go 检查点位身份、所属站、应用版本、范围、编码与命令去重。`sent`、ACK、后续新鲜物理读回和本地模拟更新不能合并成一种成功；未知/超时不能自动重发。
