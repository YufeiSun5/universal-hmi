# v38 数据库接口、同期对比与手机多账号

产品要求见 [agent.md](../../agent.md)，唯一进度见 [AI_BOARD.md](../../AI_BOARD.md)，实现合同见 [architecture.md](architecture.md)。

本批使用最终数据库接口说明接入间隔历史与日结算，新增独立“同期对比”画面，支持全站/单站、等长滑动日期窗口、明细和汇总。本期从2026-11-04开始，不补11月3日。查询复用已保存连接与外部画面授权，不在现场创建或迁移数据库对象。原始值、有效零、NULL、已结算小计、完整日及有效小时分别保留；新站无历史不阻断全站结果。

历史、日报、能耗和同期对比的界面仅显示站点名称；同期对比名称列为“站点”和“往年站名”。内部编码仍用于查询和关联。能耗移除小时入口及小时列，保留当前总览、历史日用量和开发态站区核数；历史小时报继续提供。

已批准手机的设备准入与实际登录账号权限分离，同一手机支持切换多个账号，各自使用自己的授权。设备撤销、证书期限和账号停用仍实时生效。登录提示区分可明确识别的验证码、账号及设备状态，错误口令与不存在账号保持统一提示。可选“记住密码”在登录成功后使用Android Keystore加密保存，可选择已记住账号及清除；不自动登录，不保存验证码。

公网只读入口允许任意父平台和多层嵌入，携带设备证书时也不再返回 `frame-ancestors 'self'`。兼容 `?embed=kp`，普通iframe入口自动选择分区Cookie；业务认证、设备准入及只读权限保持。

产品显示名称统一为“智慧供热集中监控系统”，覆盖主界面、登录、窗口、安卓应用和安装器。应用包名、安装AppId和工程存储路径保留原身份，确保升级可识别既有安装。
