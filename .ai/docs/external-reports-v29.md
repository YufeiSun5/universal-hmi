# 标准历史查询与历史报警 v29

## 使用

本机开发态打开「外数据」，在已有小时报使用的 SQL Server 数据源下，分别新增「标准历史查询」和「历史报警」画面。保存后在用户或角色权限中授权相应画面。已有工程升级后可沿用原连接。后台只执行受控 SELECT。

进入「历史」并选标准历史画面，打开「查询条件」，依次选择站所、换热站、区域、起止时间和分钟间隔。起点包含，终点不含，可输入到秒。站区取自外部 Station 字典，站所、换热站、区域名取当前工程总览中唯一同名的站区行，缺少归属时仍可按数据库站区选择。默认5分钟，最多15天，间隔1–21600分钟。每页500、700、1000条，也可选全部；全部按1000行分批读取。显示目标时间、实际采样时间、匹配、质量和测点列，可按组切换显示，导出全部目标时刻及当前可见列的 UTF-8 CSV。

进入「报警」会自动打开已授权的历史报警画面，有多个时可选。默认最近七个日历日，可调整起止时间、变量名包含条件和事件类型。报警恢复和确认各自占一行，事件时间和原报警发生时间分列，数据库时间不加时差。每页500行，SQL NULL 显示为 —，文本 0 保留。没有画面、无权、查询失败和无匹配事件分别显示。dbo.Operate 未接入。

## 验证范围

Go 回归使用 SQL mock 验证参数绑定、时间范围、画面授权、精确小数、缺测和可空值。Flutter 回归经真实组件入口验证三级条件、分钟间隔、目标/采样时间和恢复事件。现场 SQL Server 查询耗时、索引及权限需用现场已授权的只读画面验收。
