# 工艺画面与开发页

2026-10-09 用户授权内置免费工艺素材，并追加独立开发页用于生成模板。产品母本是 [agent.md](../../agent.md)，分层/保存合同见 [architecture.md](architecture.md)。

## 使用流程

1. 进入顶部共用「开发页」标签，在页内选择「目标站点」（或公共总调度）与画面。点击明确的「新建模板」，选择空白模板（可设画布尺寸）或「三换热器供热站（参考图）」。整个工作区只有一个开发页，目标站不会跟随外部站点标签悄悄变化。
2. 从素材库拖入设备，或点击素材后在画布按住左键拖动设置范围。矩形、椭圆工具也按住左键拖动绘制，松开完成，不再单击创建固定尺寸。使用管道工具单击起点、转折点；点击设备四边连接点可结束连接，Enter/「完成管道」结束自由管道，Esc 取消。直角折线、网格吸附可开关。
3. 文字、实时数据与设备支持拖动绘制，也保留单击放置。选中元素后拖动内部移动，四条边任意位置及四角可调整大小；另一侧保持固定，最小尺寸为 8，并限制在画布内。右侧可精确设置 X/Y、尺寸、字体和颜色；输入后直接点击画布即可提交，不必先按 Enter。
4. 选择实时数据元素，在右侧绑定点位 ID，设置变量名称、0–6 位小数、显示单位、单位文本和数值前缀。单位留空使用实际点位单位；自定义单位仅改变显示标签，不换算工程值。
5. 素材库切换「我的素材」可上传透明 PNG/JPEG、设置名称/分类，并搜索、点击放置或拖入各站画布；棋盘格预览透明区。「嵌入图片」也会先存入共享素材库再放入当前画面。可以用示例图片作为参考并通过右键「置于底层」放到背景。复制/粘贴、图层、撤销重做用于完善布局。
6. 保存后通过「在该站查看」进入目标站的「工艺画面」。每站可通过下拉框选择多张画面；各图引用、图片和变量绑定互相独立。开发页自身也有运行预览。未保存布局仍可跨页预览，界面标为「草稿预览」；退出程序前应显式保存。

工艺画面页面提供查看、选画面、缩放和平移，并有「进入开发页」入口；它不显示编辑工具。当前账户只读时，开发页也不能保存和修改。

## 模板与后续 AI 协作

画面文件菜单支持「导出模板 JSON」「导入模板 JSON」及「另存副本」。模板是可读 schema_version=1 文档，包含元素布局、文字、设备素材身份、嵌入图片及变量的 `point_id`、`decimals`、`show_unit`、`unit_override`。变量的位置由元素 `x/y/width/height` 定义；图片内容随文档携带。

可以先摆出示例并保存/导出，然后让 AI 修改同一 JSON 模板，完成对齐、管道、文案和绑定。「引用已有工艺图」从来源站选择一张图，在目标站创建独立新画面；导入也生成目标站新画面，避免覆盖原稿。跨站复用清空原 point_id，保留布局/小数位/单位，用户显式绑定该站变量；程序不会按同名变量猜测，也不会联动修改来源图。该版本不包含聊天式自动生成器、OCR 或自动识别图片中的变量；模板文档为后续协作提供明确接口。

快捷键在画布焦点内生效：Ctrl+S 保存，Ctrl+C/V 复制粘贴，Ctrl+D 复制副本，Ctrl+Z/Y 撤销重做，Delete 删除，方向键微调。滚轮缩放，中键/手形/Space 拖动平移。文本输入焦点内仍执行正常文字编辑。

## 素材与持久化

内置 458 个静态 FUXA 工艺 SVG，覆盖换热器、泵、阀门、容器、仪表和管件等 23 类。上游固定提交 `70e7c4a656d111c0428c77eb4b0409fc3670b8d5`，保留 MIT 版权及许可通知，详见 [资源说明](../../app/assets/process/README.md)。只嵌入已审阅的 `Proc. Engineering` 子集；移除脚本、事件处理器及外部引用。其他目录没有整体商用许可承诺。用户自行嵌入图片的权利独立。

「我的素材」为工作区共享功能，原始图保存在 `screens/materials/<id>.json`，重启加载；最多 256 项，单项 JSON 3 MiB。后端验证实际 PNG/JPEG、权威返回尺寸；保留原始 PNG 全透明/半透明像素。放置时复制到画面，不依赖素材库后续存在；删除素材只删库中条目，已嵌入画面保留。列表只传元数据，前端最多缓存 32 张原图。免费伪 3D 来源筛选见 [免费实物素材调查](process-assets.md)，调查中尚未内置的来源不计入 458 个素材。

文档由 Go 保存在用户数据目录的 `screens/<id>.json`；桌面与同源 Web 共用。初始 revision=0，成功保存后递增；旧版本覆盖/删除被拒绝，客户端保留修改并可另存副本。保存与运行配置激活、设备控制无关联。

实时数据采用既有后端快照；坏质量、陈旧、缺失、离线、点位移站和状态类型不支持都有明确文本。设备颜色及箭头属于展示，不表示 PLC 命令执行。默认 700 ms 刷新，不承诺更高采集频率。

## 参考图、组件适配与文件组织

参考图重绘为 1280×660 的 JSON 蓝图：三台板式换热器、五台泵、补水箱、阀门、一次/二次/补水管道和右侧十项统计，总计 120 个元素、33 个变量位置。设备是四个自绘 SVG，其他部分是原生管道、文字、矩形和变量；每个元素可移动、修改、撤销和保存。用户提供的照片未加入公开仓库。示例默认所有 point_id 为空，显示「未绑定」；照片中的 ??? 和数值不作为实时数据。

「嵌入预览」可选择 960×480、640×360、360×300、640×220。查看组件依宿主的实际可用尺寸重新计算 `scale = min(可用宽/画布宽, 可用高/画布高)`，预留边距并居中，保持设备比例和管道位置；容器改变或换文档时回到完整适配，实时值更新保持用户当前放大/拖动。超出原生元素框的数值连同单位只缩小显示，不裁掉有效数字；小容器里整图文字仍可能偏小，提示切换正常字号变量表或放大查看。总览页面嵌入同一组件：宽区域左右布局，窄区域上下布局，低高度允许滚动。宿主提供数据，组件不另开采集/轮询，也不触发设备控制。

| 实际位置 | 归属与用途 |
| --- | --- |
| `app/assets/process/templates/heating-station.json` | 随程序发布的只读示例蓝图；每次新建生成独立实例 |
| `app/assets/process/examples/*.svg` | 四个自绘设备；其余外部素材仍在 `symbols/` 并保留独立来源通知 |
| `app/lib/features/process/model.dart` | 文档/元素、坐标、端口、单位/小数与质量显示 |
| `scene.dart` / `viewport.dart` / `diagram.dart` | 共用绘制、适配算法、可嵌入只读组件 |
| `canvas.dart` / `workspace.dart` / `template_dialog.dart` | 画布编辑、文件/站点操作、新建选项 |
| `session.dart` / `overview.dart` / `preview.dart` | 站点草稿与读取、总览接入、开发页尺寸预览 |
| 运行数据目录 `screens/<id>.json` | Go 通过 REST 保存的各站画面实例，站点归属写在内容里，文件名只使用合法稳定 ID |
| 运行数据目录 `screens/materials/<id>.json` | 全站共享上传素材；放入画面时复制 PNG/JPEG 字节，原库条目删除后画面仍完整 |
| `.local/`、`output/playwright/`、`app/build/` | 忽略的开发工具/隔离测试数据、原始浏览器证据、构建产物，不是产品模板库 |

当前组织适合有明确容量上限的单本地工程：界面源码、发行素材与用户运行数据分开；后端是唯一持久化入口，原子替换与 revision 防止部分文件和旧版覆盖；稳定 ID 文件名避免站点/画面改名引起文件迁移。复制图片让模板 JSON 可携带自身图片，跨站实例互相独立。

限制也明确：当前所有站合计最多 64 张画面，单张最多 8 MiB；大量重复 PNG 会增加磁盘占用。若扩展到更多站和大量图片，下一阶段应做按内容摘要存放原图、文档引用与引用计数/回收及可查询索引，同时保留独立导出打包能力。当前「模板」是内置蓝图或可导出/引用的画面 JSON，尚无独立的用户全局模板版本库，也不会把修改自动同步到引用站。
