# 跨站显示与实际变量分站 · v13

用户选择实际调整变量归属，并允许旧站删除重建。实现由 GPT‑6.1 Sol / Terra 完成，主代理负责方案与审查。本轮不直接操作现场工程；安装升级不清理 MQTT 变量、站点或画面。

## 实现与审查

- 工艺数值和管线箭头按稳定变量 ID 获取已授权值，移除遗留的画面站与变量站必须相同的显示限制。变量权限、缺失、离线、过期及质量检查保留。
- 开发端变量设置新增“按工艺画面分站”。单站引用提供候选；共享和未引用变量保持原站，用户可明确指定目标。候选仅代表画面引用证据，不证明设备的物理归属。
- 整批保存仅调整 Station，保留 ID、MQTT 配置、工艺引用和历史。提交前重新核对版本与依赖，数据库内原子保存恢复记录和定义。保存不等于应用配置。
- 回退清单是普通 JSON，重新载入后仍须预览确认，不能绕过后续修改的版本检查。
- 旧站存在画面、变量、规则、存储或运行归属引用时禁止删除。运行快照在存储事务前读取，避免锁序倒置；需先应用配置，再核对空站删除。
- v13 安装器移除安装期重建入口及调用，执行保留数据升级。历史维护工具保留，但不会由本次安装自动调用。

主代理复核过整批回退版本保持、批量选择原站时清除旧选择、恢复记录唯一标识、保存失败可重试以及旧运行归属删除闭锁。技术契约以[架构](architecture.md#变量归属派生与存储)为准，后端详细证据见[变量归属核验](point-ownership-verification.md)。
