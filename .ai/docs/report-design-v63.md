# 报表与安全页面 v63

本批处理用户指出的热量结算/同期比较列定义、同期“截至现在”失败路径、自定义存储过程报表与样式、查询速度，以及安全菜单尤其访问历史的布局。Windows/Web完整包沿用原工程身份，不部署现场或18153，不改现场数据库。

## 使用

开发端“外数据→添加查询画面”选择“自定义报表”，选择已保存数据源、读取存储过程目录，填写参数类型/默认值并保存；再按画面授权给所需账号。参数支持文本、日期、日期时间、整数、小数及布尔值，日期提供选择器。存储过程需由数据库维护方部署为查询过程并授予当前数据库账号执行权限，软件不会创建过程或自动授予权限。

查询后点击“报表样式”，按实际返回字段编辑列顺序/名称/显隐、列宽、对齐、小数位、合并表头、字号/行高及颜色。设置保存在工程中，运行端消费相同样式；恢复当前表默认需显式保存。热量结算和同期汇总有各自列结构。CSV跟随列定义，但小数位样式不损失导出的原精度。
