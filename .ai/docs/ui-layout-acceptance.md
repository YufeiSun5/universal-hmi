# UI 布局巡查与验收说明

更新：2026-11-01。本文是分批验收记录，不是“全部界面验收完成”声明。视觉要求沿用 [普通页面设计](design.md) 与 [桌面体验](desktop-experience.md)，验证口径遵循 [验收说明](verification.md)。

## 1. 范围与证据口径

本轮针对用户提出的桌面界面秩序、窗口被挤压、边缘不齐、设备复杂过滤和主要操作不可达问题，先检查实际界面，再按独立小 PR 修复。普通业务页面保持浅色桌面软件风格；登录和 GIS 保留各自设计，不以全局换主题掩盖布局问题。

界面结构清单共 **28 组**：A01–A10、B01–B09、C01–C07、D01–D02。它们是结构分组，不是 28 个页面，也不是截图数。此前“29 组”属计数错误，应以此处为准。

对 `app/lib/**/*.dart` 使用正则 `\bshowDialog(?:<[^>]*>)?\s*\(`：基线 `c60716b8` 为 71 个调用点、22 个文件；已合并的 `a2df5def` 为 73 个调用点、22 个文件。调用点并不等于独立界面；外部查询弹窗合并后的 `43ffe37e` 为 74 个调用点、22 个文件。

本轮视觉证据来自**真实 Flutter 测试渲染器**，使用合成记录、合成长中文、独立路由与弹窗。测试环境缺少系统中文字库时，仅在截图辅助层补字体，不更改产品字体。它不是 Windows/macOS 真机窗口管理、系统缩放、多屏，也不是浏览器 WebView/GIS 地图验收。截图数量和“没有抛异常”均不能单独证明交互完成。

状态约定：
- **已查（部分）**：已实际渲染该结构的列明状态，其他分支仍待验。
- **已修**：修复有专项测试；是否已进入主分支另列。
- **待验／限制**：不把静态阅读或其他同类页面的测试替代此项验收。

## 5. 有界剩余项与停止条件

本轮不再以无限微调的方式扩展风格 PR。发布前优先关闭以下风险：

1. **当前组合门禁**：#35–#38 精确 PR 提交 CI 均已通过并合并；#35/#36/#37 各自合后运行被后续主线替代而取消。最新 `12dbe23e` 的合后 CI 仍待终态；失败先定位，不能把取消或其他提交绿灯记作当前通过。
2. **GIS 平台差异**：在获准的 Web／桌面地图环境验证非空站卡分区、点击打开目标、站区编辑保存／取消；测试占位图不算通过。没有可用环境就保留明确限制。
3. **启动与账号关键状态**：账号底部与退出取消补验已通过；再确认会话不可用／重试、恢复码显示后离开、会话审计长列表可读。合成账户即可，不要求真实密钥。
