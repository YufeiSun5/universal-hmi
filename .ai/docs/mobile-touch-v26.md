# 手机目录收起与 GIS 触摸 v26

接续[目录默认首项 v25](mobile-directory-v25.md)，同一任务LIVE-OVERVIEW-v23。用户已在v25真机确认“不错，可以了”，随后明确完全收起目录、只留展开按钮，并新增GIS单击浮窗/双击配置动作要求。v25Windows封装停止，最终改为0.1.0.26。

## 实现

Flutter手机外壳独立管理目录显隐。Offstage保持目录实例，收起后内容宽度恢复全屏，仅侧边44×48px按钮恢复；展开完整树、直接选项、自动首项和历史当天自动查询继续保留。显隐不重建查询，不发额外请求或写工程。桌面/Web原布局不变。

GIS站标运行层使用PointerEvent区分触摸和鼠标。单次短点立即固定浮窗；同一目标在360ms、24px内第二点沿原gis-open-station触发一次配置跳转。超过12px移动、双指、取消、超过600ms长按、切换目标、离开页面均不会组成双击；过滤触摸合成click，保留鼠标和键盘激活。点地图空白关闭浮窗，开发态拖动不接入此运行规则。

## 返回与登录保持追加

仅安卓子页面提供48px返回行，保留已确认底栏；有界模块栈恢复此前画面，GIS为首页。系统返回先关闭弹层/抽屉，然后退回上一模块，首页原生确认后moveTaskToBack，不finish、不调用logout。原生不再onStop销毁WebView；进程重建通过独立Keystore AES-GCM身份存储恢复有效会话，作用域绑定服务器、pin及设备公钥，不保存密码、不向JS提供Cookie。服务器8小时绝对期限、30分钟空闲及撤销仍生效，恢复登录不是扩大授权。

真实浏览器触摸曾发现浮窗盖住站标，导致第二点被卡片拦截，已修复为避让目标并按可用高度滚动；竖横屏与边缘几何回归通过，实际CDP触摸确认单击浮窗且站标可点，双击仅一次跳转。

原生会话专项覆盖重建恢复、到期、删除/退出、非安全或不同域Cookie拒绝、非持久Cookie不恢复、写盘失败不报告登录成功；真实mTLS代理测试覆盖跨实例恢复、退出清除及身份Cookie不进入WebView。Flutter回归覆盖返回上一模块/首页且不注销。
