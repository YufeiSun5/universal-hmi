2026-10-02。范围来自用户本轮明确指定的五项：读取缩放/偏移、写入缩放/偏移、定时存储、条件存储、条件触发脚本。沿用现有界面及 Go 业务权威，不扩展任意系统脚本能力。本轮测试基点为 `05573ed402d1b04850ebdf433f1c625c43f222fe`。

## 本轮修复的实际问题

- 旧整数逆算允许过宽的固定原值容差：倍率 `1e12`、请求工程值 `100` 可被舍入为原值 `0` 并报告成功。改为检查类型可表示性和正向换算回环，拒绝下溢、溢出、偏移抵消及不可表达的目标；正常十进制整数编码保留浮点舍入余量。
- INT 不按数值幅度放宽舍入：例如 `1e15 + 0.25` 仍拒绝。仅接受正向精确匹配，或最短十进制表达有理数逆算能证明的整数；十进制过零残差还须同时满足操作数舍入界限及单个原值步长的 1e-9 上限，不把大偏移造成的实际差值放行。历史保留真实 float64 工程值，不伪造精确零。
- 旧读回在工程值域按相对误差比较，大偏移可把错误原值当成正确值。改为在原值域核对；INT/BOOL 精确比较，FLOAT 只容许浮点计算舍入误差。
- INT 读取统一采用可精确表达的整数范围，越界标记坏质量，不继续显示为正常数值。
- 原始非有限数（包括虚拟除零生成的 NaN/Infinity）曾使整个运行快照 JSON 或存储失败。现在工程值为空、质量为 bad，原值保留为 `NaN`/`+Inf`/`-Inf` 诊断字符串，其他点位继续可查询和存储。
- 重复开始存储或保存相同策略曾重置计时及变化缓存，导致额外落库。相同策略现在保持原采样状态。
- 界面提交完整规则列表曾重置全部边沿状态，保存无关规则也可能再次写入/存储。未变执行语义的规则保留持续、边沿及冷却状态；仅修改名称也不重放动作。
- 不同站点的成功存储曾清掉失败站点或规则审计的错误。错误按操作作用域保留，只由同一操作后续成功解除。
- 当前进程最多保留 256 条存储/审计失败详情；超限保留明确警告至重启，不能据其他操作成功推断未记录失败已恢复。
- 条件阈值缺失/null 曾隐式变为零。现在要求显式数值，零仍合法；预览及保存都拒绝缺失阈值。
- 预览与保存复用规则结构校验；无效规则返回未知/不成立及错误，不再把空条件等无效定义显示成成立。
- 比较运算符按六个合法值逐一匹配，拒绝 `>|>=` 等拼接字符串。界面明确显示规则校验错误，不把它误报成数据陈旧。

## 有意保留的语义与边界

- 工程值由 Go 计算：`raw * scale_factor + offset`；写入目标是工程值，逆算为 `(value - offset) / scale_factor`。BOOL/STRING 只允许单位换算；STRING 物理写入不支持。
- 历史冻结采集时的原值、工程值、单位、版本、源时间和接收时间。**目前没有独立“落库/采样时刻”字段**：定时存储同一个源样本时，源/接收时间保持相同。周期证据来自扫描时间及持久行数，不能拿源时间冒充落库时间。
- 条件“脚本”是现有受限动作序列：受控写入、快照、开始/停止独立存储；不执行 shell、任意进程或外来代码。动作可部分成功，后续动作和每步状态必须可查。
- 预览只判断当前条件，不执行动作；启用规则后后台按现有扫描周期执行。首次成立、持续成立按冷却周期、恢复是不同触发方式。
- 重启恢复策略和历史，不重放旧运行样本；规则恢复为禁用，不自动连接来源或重发未知物理命令。存储在新鲜数据到达后可按已保存策略继续。
- 当前未知质量后的边沿重新武装、冷却期间被抑制的上升沿等沿用现有语义，本轮不另行引入新的执行策略。

## 检查命令

使用固定 Go 1.24.7 与 Flutter 3.35.4 / Dart 3.9.2。在后端目录执行：

~~~sh
go mod verify
~~~
