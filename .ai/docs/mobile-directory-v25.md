# 安卓可直接操作的目录与默认查询 v25

接续[手机体验修订 v24](mobile-polish-v24.md)，仍属唯一活跃任务LIVE-OVERVIEW-v23。用户已在v24真机登录并认可简洁底栏；随后明确目录收窄状态也须能点选条目，并要求默认打开第一项、历史自动查询。

## 实现边界

- Flutter运行外壳和公共紧凑目录组件：96px常驻可滚动列表，名称/分组/选中项可见，点击直接切换；展开按钮与画面选择分开，完整树仍可搜索和选项。
- 工艺目录复用现有screens/navigation接口，按配置顺序打开首个有效画面，失效目标不循环重试；不写工程或导航配置。
- 历史目录复用ExternalCatalog与ExternalQuery；安卓自动选择首个授权画面，站点加载成功后查询默认当天范围一次，换站刷新，其他重绘/刷新目录不重复查询。空目录/空站点/失败保留明确状态；原generation检查避免旧结果覆盖新选择。
- Android底栏、状态栏、中文字体及GIS半透明沿用用户认可版本；桌面/Web目录及查询默认保持，开发态不自动触发查询。后端权限和查询限制保持。

## 验证

自动专项已验证：配置顺序优先而非站点字母顺序、跳过失效首项、不展开直接切换、展开仍可使用完整树；历史首项/默认当天查询一次、切换画面重查、重载目录不抢回首项且不重复查询。最终全回归、同源构建、APK真机和Windows保留覆盖验证在途。
