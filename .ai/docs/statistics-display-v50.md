# 统计展示 v50

本批按用户分工只处理软件展示与接口消费，数据库统计及来源配置由数据库任务处理。产品要求见[agent.md](../../agent.md)，显示合同见[设计规范](design.md)。

## 结果

- 客户运行态和CSV只保留业务数据，屏蔽数据库诊断、统计进度、采样截止及核查小计列；开发态继续保留诊断字段及布局配置。
- 能耗优先显示接口已有的`day_usage`，为空时消费已有`day_subtotal`，保留有效零和其余业务数值。未重算日用量，也未使用小时值替代日值。
- 小时报本次查询完全没有数值的测点不占列；某些小时缺值不会隐藏该测点其他时段的有效数据。缺值显示“—”，不补零。
- Go业务、现场库、变量绑定和工艺画面无改动。

## 验证

Flutter analyze通过，完整回归615项通过、2项既有浏览器专用测试跳过；15项专项覆盖诊断与业务分离、已存小计、零值、部分缺值、全空测点和实际CSV落盘。安卓15项测试、lint、原签名及5740项内置Web资源核验通过。Windows和Web来自同一源码摘要，完整安装器和同签名APK均已生成。

实际Chrome使用隔离后台、正常API登录和合成查询响应（浏览器拦截），验证1440×900桌面及390×844窄屏；能耗和小时报实际导出的CSV没有诊断字段，数值与界面一致。小时报确认全空循环泵3不占列、温度部分缺值保留、零值保留；控制台0错误0警告。截图和导出见[证据目录](evidence/20261106-v50/release.json)。此检查不代表现场数据库结果已修复。

v49→v50隔离覆盖、启动、重装及卸载通过，保留5019变量、31图、12表、账号、图片、来源绑定、导航、批准设备证书和采暖季价格。工程业务文件字节与PG业务内容核对通过；维护日志和操作结果文件按原机制更新。测试后台/端口已清理，原快捷方式已恢复。
