# v100 入出库汇总查看与导出

2026-11-16用户提供《材料出入库明细表（终版）.xlsx》，随后明确本轮只做入库＋出库汇总，先使用已有数据，缺失字段留空。库存、暂估、冲销工作表不在本轮；原稿中的历史业务数据不导入，也不随程序发布。

## 范围与合同

materials增加只读PeriodReport和ExportPeriodReport，server仅解析公开请求与返回文件。Flutter物料工作区增加“出入库汇总”，入库/出库按原权限分开查看；具有两项权限时可合并导出。保持现有物料在手机导航隐藏的约束。

按北京时间起止日期、分类（含子类）、物料名称/规格/单号/领用方查询。开始包含、结束为下一自然日零点排除；默认本月至今天，可选今天/上月；一次最多366天，每类最多10000行，超过明确失败，不静默截断。页面50行分页，金额/缺价/按单位数量取整个匹配范围，不随翻页变化。分类和物料搜索应用到明细行，不能把同单其他不匹配行一起计入。

每条明细对应原已确认单据行，按办理时间、单据ID、明细ID稳定排序。点击可打开原单。数量、单价、金额读冻结快照，零与缺价分开；不修改单据、库存或原始签名。入库与出库独立排列，不推断两边同一行对应同一批物料，退库不冲减原出库明细；退库仍在既有出库管理中单独查看。

Excel同一工作表左A:M入库13列、右N:AD出库17列，参照模板主表（含站所列）；单类导出保留本侧完整字段。日期、名称、规格、单位、数量、单价、金额使用真实原单数据；出库领料单位取现有领用方。发票号、供应商、主管、采购员、保管员、性质、工程项目、站所、工程编号、供应审核及领用人等没有独立可信记录时留空，不从备注、当前用户或请购角色猜测。每侧分别合计，缺价标“已知小计”。查询和导出共用同一行投影；合并导出在同一只读事务快照读取，生成文件前释放数据库事务，输出前复验身份。Excel内容均显式字符串，避免执行业务文本中的公式，保留原十进制精度。
