## 实现

Flutter external_data/report_designer 将编辑器扩大到可用窗口高度，按“列设置、上层标题、外观”切换；默认列设置独占主要空间。桌面每行44px、窄屏53px，列内容单行排列，较窄窗口横向滚动；字段来源独立单行及悬停提示。选中列后上移/下移按钮固定在列表外，保存/取消固定在底部。颜色、字号、报表行高移入外观页。小窗口保留触控面积和按钮间距。

ReportStyles 登记原分组标题及稳定组标识。report_layouts 的 group_labels 保存原组或自定义组的显示别名；同名别名不合并不同来源身份。DenseTable 与 CSV 使用同一标题投影，改标题/顺序不改变原字段绑定、NULL、零或十进制数据精度。后端 externaldata 在原画面保存契约中验证上层标题的大小、空值与非法字符；原权限/revision控制保持。

编辑器导出当前表格的 UTF-8 缩进 JSON，包含格式/版本/报表类型/稳定字段说明、原组说明及 layout。AI 可修改上下层标题、列数组顺序、显隐、宽度、对齐、小数位及外观；字段 key 不变。导入严格检查格式、版本、报表类型、当前字段集合/重复字段、可见列和样式范围，只载入草稿，点击保存样式才走原API；错误不修改当前草稿。不导出账号凭据或数据库过程定义，不执行文件内容。保留其它表格及当前未查询站区字段的既有样式。
