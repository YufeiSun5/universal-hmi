# v83 报表单行工具栏、加载与原稿隐藏设置

## 范围

用户要求将截图中标题/操作两行合并，报表打开较慢时显示loading，四份报表尊重Excel隐藏列，并删除采暖计划的红色部分、下方上移。用户随后明确：失去来源的指标也一起删除；同时支持原页替换与删除页面，并统一文件选择按钮UI。

软件改动属于`totalreports`及其嵌入编辑器，沿用现有HTTP/宿主文件导出合同。未修改外部历史库、权限、数据绑定、现场工程或18153。安装包和新版计划Excel独立交付，不自动将旧计划的已填内容替换为模板。

## 实现

- 标题、保存状态、Excel导出、历史及开发操作合为49px单行工具栏；窄窗按需横向滚动。
- 静态HTML在JS下载前显示加载动画；React接管后覆盖目录读取、文档读取和首次表格重算。切换期间禁用年份与目录操作；失败清除loading，允许重试。
- `Service.Sheet`从年度冻结的不可变Excel原稿读取`colhidden`，固定页面同时读取`rowhidden`。旧年度无需重新导入，隐藏只影响显示，单元格仍用于公式及导出。季节行由新日历生成，不套用原稿旧行号。
- 核对原稿：热、电无隐藏列；水隐藏C/D；采暖计划隐藏W/X并保留原隐藏行。补充中文Excel内置57格式，计划月份显示年月而不是日期序号。
- 计划模板删除原19–44、82–83共28行红色内容；按用户确认再删除16行直接或间接失去来源的指标（原7、50、52、65–69、71、74–78、80–81）。保留值与210个公式，公式随删除重定位；恢复跨删除区域的分类合并标题。原档未改。

## 使用

覆盖安装v83后，关闭并重新打开报表页面；已有水表隐藏列自动生效，热/电/水不需重导。

已有采暖计划：开发端选择原页面及年份 → 页面管理 → 选择精简版XLSX/Sheet1 → 预览整页替换 → 核对并确认。替换仅覆盖当前年份，保留页面名称和入口，其他年份及新建年度种子模板不变。上传文件中的数值、公式和格式覆盖整页，旧历史绑定移除；不会按行号自动迁移已填值。替换前保留整页备份，通过配置历史恢复。

也可以通过“添加页面”独立导入。新版模板仍包含原非红色计划/同期数值，应按实际业务核对后使用。

删除页面：页面管理 → 删除此页面 → 核对全部年份并确认；从各终端目录移除且拒绝读写/导出，原数据保留。在页面管理的“已删除页面”恢复。此操作仅适用于自行添加的页面，内置热、电、水报表不在删除/整页替换范围。
