# v37 普通账号登录保持

产品要求见 [agent.md](../../agent.md)，唯一进度见 [AI_BOARD.md](../../AI_BOARD.md)，会话合同见 [architecture.md](architecture.md#普通登录保持2026-11-04v37)。

本批修复普通账号、浏览器设备及安卓设备在闲置30分钟或登录满8小时后自动退出的问题。后端普通身份会话不再设置这两项超时；新版Flutter识别明确的 `identity-v1 / no_timeout` 策略，不再启动本地退出计时器。网络错误及503保留登录，401及明确撤销仍按原流程退出。

身份Cookie保存365天，读取已认证会话时续期；Cookie仍为HttpOnly并保留Secure、SameSite、KP嵌入分区属性。旧客户端仍收到可解析的兼容期限，但只有更新内置Web后的安卓APK才能完全取消本地8小时计时器。用户停用、权限版本变更、主动退出、管理员撤销、设备证书及审批状态仍实时核验。历史KP联邦入口继续受上游登录约束。

会话当前保存在后端进程内存，后台服务重启后需要重新登录。本批没有实现会话跨服务重启恢复，不保存账号密码，不改变现场控制或公网只读边界。
