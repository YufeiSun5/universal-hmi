# 运行端界面整理 · 2026-10-28

本批按用户要求保留 GIS 视觉，检查并重整工艺画面菜单和其余运行页面。产品母本为 [agent.md](../../agent.md)，技术边界见 [架构](architecture.md)。不改写已保存工艺图背景、GIS 数据、变量归属、账号权限或采集配置。

## 实现

- `app/lib/features/process/runtime_chrome.dart` 提供运行端浅色主题、深蓝导航、页标题/连接状态、独立站点范围及筛选工具栏。窄窗口提供「全部页面」菜单，筛选横向滚动条可拖动。
- `monitor.dart` 与 `screen_explorer.dart` 重整蓝白工艺目录，宽窗口可折叠、窄窗口抽屉显示，选图后关闭抽屉。修复窄窗口按钮取错 Scaffold 导致无法打开目录的问题。
- `page_navigation.dart` 保留分组名打开首个有效目标、箭头仅折叠、画面归属独立、搜索保留路径的既有语义；增加层级留白和明确选中背景。
- `main.dart` 的数据总览/历史报表/历史数据使用站点范围目录，切站留在当前页面；设备台账与外数据保留各自业务目录。运行态不因工程师登录而出现开发编辑入口。
- 工艺画布继续使用文档自己的背景；没有修改用户图纸或将深色图纸自动改为浅色。GIS 继续使用原透明导航与地图。
- `equipment/workspace.dart` 在低高度内容区允许整体滚动，保留设备列表空间；修复600×600时筛选区挤掉全部设备行的问题。
