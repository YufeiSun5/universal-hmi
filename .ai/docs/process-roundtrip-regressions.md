# 工艺资料往返验证

模板与工艺资料包不是同一种交付物：

| 路径 | 预期语义 | 可重复回归 |
| --- | --- | --- |
| 画面操作 → 导出/导入模板 JSON | 复用布局、图片、背景、变量槽位与显示格式；清空实际变量和箭头条件的点位绑定；导入目标站生成新画面，重新绑定后另行保存 | `app/test/process_template_file_roundtrip_test.dart` |
| 工艺资料 → 完整工艺包 JSON/XLSX | 导出画面及被引用变量、派生输入；预览后按目标站映射保存，数值与箭头条件引用映射后的变量 | `backend/internal/transfer/bundle_roundtrip_test.go` |

## 执行

使用仓库锁定工具链并按 CI 准备离线字体后：

```sh
cd app
flutter test test/process_template_file_roundtrip_test.dart
```

```sh
cd backend
go test -race ./internal/transfer
```

前端回归使用真实 Flutter 菜单和平台保存/读取代码，在测试临时目录写出 JSON，再导入另一站并保存；文件选择器由合成替身提供路径，画面 API 为测试替身。它检查每一跳的布局、图片与背景，清绑定和保槽位的差异，以及源画面不变、目标新 ID/版本/草稿状态。不会打开操作者的文件选择窗口或写用户工程。

后端回归使用真实导出服务、JSON/XLSX 编解码、预览、提交和临时仓库，检查精确变量/派生输入/数值及箭头绑定映射、完整画面结构、图片和背景；预览不写入，重复导入不重复创建或改变已保存结果，源工程不变。

## 覆盖边界

这两组回归是分层语义验证，不是浏览器到生产后端的完整部署验收。未涵盖真实现场采集、原生文件选择器交互、所有共享实例展开组合或真实设备 DPI。模板回归走原生保存实现，不能据此声称 Web 下载已落盘。完整工艺包测试不表示包含客户端导航迁移；画面引用和派生依赖会自动补齐，显式勾选变量数也不等于最终导出总数。
