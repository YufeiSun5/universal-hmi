# 供热运行驾驶舱 v108

运行端从现有顶部菜单进入驾驶舱。近七天用量按热、电、水分别显示今日累计、统计截至时间和趋势。列表超出画面时逐行缓慢滚动。开发端通过「运行与历史 → 驾驶舱配置」选择能耗来源、参与汇总的站区并设置延迟和离线阈值。

天气卡片同时显示总览绑定的室外测点实测温度和和风实况。和风还提供未来 24 小时气温及三天预报。和风需填写经纬度，并在后台进程运行环境配置 `HMI_QWEATHER_HOST` 和 `HMI_QWEATHER_KEY`。各来源缺值独立显示。
