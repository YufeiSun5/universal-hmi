# 数据总览、手机适配与 v23 交付验收

2026-11-02。产品母本为 [agent.md](../../agent.md)，业务边界为 [架构](architecture.md)。本批接续并包含 [v22 安全入口与外站修复](security-navigation-v22.md)。

## 实现

- 数据总览在工艺图之后，参考庄河 HTML 实时报表的分组表头与站点行结构，采用现有中性浅色风格。开发态“运行与历史 → 数据总览配置”编辑分组、列、行、排序、小数位和已有变量绑定；客户端只读。新工程和覆盖升级都不猜测现场变量绑定，需显式配置。
- `overview` 保存展示配置，绑定既有稳定变量 ID；显示沿用实时质量与实际单位，断线/坏质量不显示伪正常值。站点和变量权限双重裁剪，公网禁止配置写入，修订冲突保留草稿，被引用变量不能直接删除。
- 报警记录独立占位。后续读取与历史相同的现场外部连接；未获得表结构，未实现报警查询、报警规则或数据库扫描。占位明确“尚未接入”，不显示“暂无报警”。
- 安卓专用底部纯图标导航与更多菜单，顶部无系统标题，桌面/Web保持原导航；数据总览默认选择站点查看分组指标，另可打开完整表格。工艺图支持双指缩放/平移与双击复位，只有视图变化，不改工程。
- 安卓内置 Flutter Web、字体和 GIS 静态资源；业务/API/验证码仍在线通过设备 mTLS 获取。地图按设备像素渲染；底图仍是原有 10 米影像，未增加真实影像分辨率。
- 固定正式地址与服务器公开证书，沿用既有 APK 签名和设备密钥。覆盖升级不能卸载或清除应用数据。Windows 先升级，再覆盖 APK；现场旧 v21 不提供新的总览接口。

- 总览修订按参考实际31项显示指标对齐，站所/换热站名称/区域三列独立多选、搜索、重置，紧凑双行指标与单位表头、26px桌面行，室外温度按已有变量可选绑定。
- GIS站点和分区的fields有序列表可增删、改名、排序和绑定；缺省兼容原五项，显式空数组不会自动恢复。仅开发态维护，删除展示项不删除变量。地图拖动导出保留字段，手机浮窗238px宽且高度有界滚动。
