# Windows 双端单实例与托盘验证（2026-10-29）

状态：实施、主代理审查、自动回归、原生窗口交互及固定 18153 升级完成。物理托盘区鼠标操作、Explorer 重启、完整 DPI 矩阵及现场设备未验；未制作新安装 EXE。

用户确认开发端、用户端各自单实例，并确认关闭到托盘、最小化到任务栏。主代理负责方案、调度与审查；6.1 Sol 实施 Windows runner、Dart 生命周期与退出草稿保护，6.1 Terra 实施启动器工程身份和隔离回归脚本。

## 行为与边界

- 同一 Windows 用户/登录会话、同一工程目录，开发端与用户端分别单实例。重复启动唤回已有窗口；两个角色可同时运行，不同工程互不限制。
- 关闭按钮与 Alt+F4 收起托盘，普通最小化保留任务栏。系统菜单提供“收起到托盘”和“退出此端”；托盘菜单提供打开/退出，窗口标题和托盘提示区分两端。
- 实际退出提交聚焦输入并检查所有保留的工艺/GIS 草稿，可取消、全部保存或放弃修改；保存中及保存失败阻止退出。
- 正式工程双入口向客户端传入实际工程目录及共享服务地址；退出一个客户端不停止共享服务。裸 EXE 的旧自有后端模式增加跨角色保护，双端并存须使用工程快捷方式。裸 EXE 与正式入口混用不属于本批共享服务生命周期保证。
- 托盘注册失败时保持窗口可见；Explorer 重启尝试重新注册，失败恢复窗口。系统关机消息不被收托盘逻辑吞掉。
- Windows 平台适配不增加业务 API、权限或物理控制。Web 保持无原生托盘行为，Linux 沿用既有退出排空路径。

## 审查重点

实例握手先于后端启动与首帧；锁基于用户、规范化工程路径及角色，不依赖版本目录或窗口标题。互斥量支持进程崩溃后的接管。显式退出先经过草稿 guard、owned/reused 后台停止语义及渲染排空，再批准原生退出，避免退出再次触发隐藏。

新增回归覆盖角色/endpoint 规范化、退役工作区解除 guard、重复启动拒绝、并发退出合并及取消后重试、聚焦输入与隐藏 GIS 草稿、保存冲突保留、保存中阻止退出。
