## 一、建设目标

在现有软件中增加物料管理功能，覆盖文字申请、审批、物料分类、入库、库存查询与预警、出库、分批退库、品类转移、个人签名和出库单 Excel 导出。

采购环节在线下处理，不在本模块中建立采购流程。手机端支持方便地拍照、选择图片并上传纸质入库清单。

## 二、软件功能清单

| 序号 | 功能模块 | 功能内容 |
| --- | --- | --- |
| 1 | 用户与权限 | 复用现有账号，分别配置申请及查看、查看及审批、入库、出库、品类管理五项权限；同一账号可拥有多项权限。 |
| 2 | 个人电子签名 | 每个用户可上传、维护自己的签名图片；审批通过、出库和退库记录使用实际操作人的签名。 |
| 3 | 物料申请 | 有申请权限的用户以一段文字提交需求，查看本人申请及处理状态；申请时不要求填写结构化物料明细。 |
| 4 | 申请审批 | 有审批权限的用户查看全部申请，执行通过或驳回；一名审批人通过即完成审批，自动附上该审批人的签名。 |
| 5 | 驳回重提 | 驳回填写原因；申请人可修改被驳回的申请并重新提交，保留原申请、修改和审批记录。 |
| 6 | 品类管理 | 支持多层父子分类，分类数量不预设业务上限，层级最多10层；具体物料归属到分类下，支持入库时快速选择或新建。 |
| 7 | 物料档案 | 维护物料名称、规格、计量单位、所属品类、库存预警值等信息；不同规格或单位分别记账，支持单价记录。 |
| 8 | 物料入库 | 选择已有物料，或在有相应权限时快速创建分类、物料；填写数量和单价。支持独立入库、关联已通过申请入库及分批入库。 |
| 9 | 入库凭证 | 每张入库单可上传多张纸质入库清单照片，图片归属于整张单据，不按物料逐项上传；凭证允许不传。 |
| 10 | 库存查询与预警 | 查看物料当前库存、所属品类、单位和预警值；库存小于或等于预警值时，在库存页面标红并显示低库存提示。 |
| 11 | 物料出库 | 有出库权限的用户直接办理，无须先提交出库申请或经过审批；填写物料、数量和用途，确认后扣减库存并附操作人签名。 |
| 12 | 出库用途 | 默认用途为“日常维修领用”，支持选择其他用途或自行填写。 |
| 13 | 出库单与导出 | 正式出库后自动生成出库单，支持导出 Excel，导出文件保留物料明细、用途和签名图片。 |
| 14 | 分批退库 | 由原出库人选择原出库单办理，支持一次或多次部分退库；退回数量补回库存，累计退库数量不得超过原出库数量。 |
| 15 | 品类转移 | 支持把物料转移到其他品类，包括“废品”品类；保留转移前后品类、操作人和时间等记录。 |
| 16 | 历史记录 | 保留申请审批、入库、出库、退库及品类转移记录；历史单据保留当时内容和签名，个人更换签名不影响旧记录。 |
| 17 | 多端使用 | 所有端提供与账号权限对应的业务功能；手机适配拍照上传、表单操作、单据查看及导出。 |

## 三、权限规则

权限按以下五项配置，不额外拆出独立的申请查看或审批查看开关。

| 权限项 | 可执行操作 | 数据范围 |
| --- | --- | --- |
| 申请及查看 | 提交申请、查看申请、修改被驳回的申请并重提 | 本人申请 |
| 查看及审批 | 查看申请、审批通过、填写驳回原因 | 全部申请；不得审批本人申请 |
| 入库 | 新建入库单、选择已有物料、上传入库清单图片、确认入库 | 单仓库内相关入库业务 |
| 出库 | 新建出库单、填写用途、确认出库、导出出库单、办理本人原出库单的退库 | 单仓库出库业务；退库限本人原出库单 |
| 品类管理 | 维护分类及物料档案、设置预警值、办理品类转移 | 单仓库分类与物料 |

- 同一账号可以同时具备申请、审批、入库、出库及品类管理权限，但不能审批自己提交的申请。
- 入库页面的快速新建分类、物料操作需要同时具备品类管理权限；只有入库权限时可选择已有物料。
- 页面展示及实际操作均按账号权限控制，不能仅靠隐藏按钮限制操作。
- “废品”是物料分类，不因此增加单独的删除或报废审批权限。

## 四、业务流程与规则

### 4.1 申请与审批

1. 申请人填写一段文字并提交。
2. 审批人查看待审批申请，选择通过或驳回。
3. 通过后记录审批人、审批时间和该审批人当时的签名。
4. 驳回时填写原因，申请人修改后可重新提交。
5. 保留历次申请内容及审批记录，不用修改后的内容覆盖之前的审批依据。

申请用于需求表达，不要求申请人预先建立物料档案，也不强制录入数量、规格等明细。

### 4.2 分类与物料

- 分类可按业务需要逐层建立，例如“维修材料 → 管材 → 钢管 → 镀锌管”。
- 分类层级最多10层；分类下面建立具体物料，例如“DN25镀锌管”。
- 库存数量、单位和预警值记在具体物料上，不将父子分类的数量重复计入库存。
- 数量允许小数，例如1.5米、2.5千克；不在本期增加自动单位换算。
- 支持记录单价，不需要供应商管理。

### 4.3 入库

1. 新建入库单，可独立办理，也可关联已经通过的申请。
2. 选择已有物料；具备品类管理权限时，可快速创建分类和物料。
3. 填写本次入库数量、单价等信息，一张入库单可包含多种物料。
4. 可上传多张纸质入库清单照片，也可不上传。
5. 确认入库后增加库存，保留本次入库记录。

同一申请允许关联多次入库。由于申请只包含文字，系统记录关联入库明细与数量，不自动推断文字中的计划数量或自动认定申请已经全部到货。

### 4.4 出库

1. 有出库权限的用户直接新建出库单。
2. 选择物料并填写数量、用途等信息。
3. 用途默认“日常维修领用”，可改选或自行填写。
4. 正式确认出库时扣减库存，并固定保存当前操作人的签名。
5. 自动生成出库单，支持导出 Excel。

- 库存不足时禁止出库，不允许形成负库存。
- 出库不依赖前面的需求申请，也不增加出库审批环节。
- 使用出库操作账号自己的签名，不要求领料人另有账号或现场手写签名。
- 重复点击或网络重试不得重复扣减同一笔库存。

### 4.5 退库

- 由原出库人针对本人办理的原出库单操作，不改为入库人员代办。
- 支持按物料、按数量分批退回。
- 每次退库保留独立记录，并关联原出库单，使用操作人自己的签名。
- 累计退库数量不得超过该物料在原单中的出库数量。
- 退库成功后增加库存，不删除或改写原出库事实。

### 4.6 品类转移与“废品”

此前沟通中的“库房里直接作废”最终明确为：将物料转移到其他品类，例如转入“废品”品类。

- 品类转移不等同于删除物料、删除历史记录或将库存清零。
- 转移前后仓库总数量保持一致，并保留操作记录。
- “废品”按分类管理，可作为转入目标；转移目标不限于“废品”。
- 本期不据此增加单据作废、实物销毁或报废核销流程。

### 4.7 签名和历史记录

- 电子签名采用用户上传的图片。
- 审批通过使用审批人自己的签名；出库和退库使用实际操作人的签名。
- 已完成单据固定保存当时的内容、操作人、时间及签名。
- 用户后续修改个人签名，不替换历史单据上的签名。

## 五、出库单内容

出库单采用适合打印的 A4 排版，导出格式为 Excel（`.xlsx`）。

| 内容区域 | 字段 |
| --- | --- |
| 单据信息 | 出库单名称、单号、出库日期 |
| 物料明细 | 物料名称、规格、单位、出库数量 |
| 业务说明 | 用途、领料人、备注 |
| 办理信息 | 出库经办人、办理时间、经办人签名图片 |

领料人为单据信息，不因此新增领料人签字要求。单价在出库单中的展示方式、单据抬头和具体打印样式在开发前细化。

## 六、多端要求

| 终端 | 要求 |
| --- | --- |
| Windows 客户端 | 完整业务办理、分类管理、库存查询、图片上传、单据导出。 |
| Web 浏览器 | 按账号权限提供完整业务功能，支持图片选择上传与 Excel 下载。 |
| KP 嵌入端 | 接入同一套账号与业务权限，提供对应的物料管理页面和操作。 |
| 安卓客户端 | 适配手机页面，支持拍照或选择图片、上传多张入库清单、业务办理和单据导出。 |
| 手机浏览器 | 支持移动布局、拍照或选择图片上传、业务办理和 Excel 下载。 |

各端共用同一套库存和单据数据，不分别维护库存账。

## 七、本期范围边界

- 只管理一个仓库，不包含多仓库调拨。
- 采购在线下处理，不包含采购订单、供应商管理、采购付款及财务核算。
- 申请为纯文字，不增加必填的物料申请明细表。
- 审批为单级，一人通过即完成，不包含逐级或多人会签。
- 出库不增加申请和审批步骤。
- 预警在软件库存页面展示，本期不增加短信、微信等外部通知。
- 导出格式为 Excel，不将 PDF 列入本期交付范围。
- 电子签名为上传图片，不包含第三方电子签约服务或手写签名采集。
- 当前只整理初版需求，开发、测试、打包及部署尚未启动。

## 八、开发前需要细化的事项

以下事项不改变上述已确认范围，后续细化时再确定具体交互和默认值。

| 事项 | 需要细化的内容 |
| --- | --- |
| 品类转移数量 | 整项物料变更品类，还是同时支持部分库存转入其他品类；部分转移时的物料档案关系，以及原出库单退库后的归类方式。 |
| 单价规则 | 单价是否必填、保留小数位数，以及是否在出库单展示单价和金额。 |
| 用途选项维护 | 除默认值及自行填写外，是否提供统一选项维护入口及其权限归属。 |
| 签名与凭证限制 | 图片格式、单张大小、单据图片张数，以及用户未上传签名时的操作提示。 |
| 单据格式 | 单位抬头、编号规则、字段必填性、列宽、分页和打印样式。 |

## 九、后续验收要点

1. 五项权限可以分别配置，越权用户不能通过页面或接口操作；申请人只能查看本人申请，不能自审。
2. 纯文字申请能够提交、审批、驳回修改及重提，历史记录和审批签名完整。
3. 分类层级、具体物料、单位、小数数量及预警值按规则保存和显示。
4. 独立入库、关联申请入库、分批入库以及无图、多图入库均可完成。
5. 出库直接办理，签名对应操作账号；库存不足和重复提交不会造成错误扣减。
6. 原出库人可以多次部分退库，其他用户不能代办，累计退回数量不能超出原出库数量。
7. 转移品类不丢库存或历史记录，转入“废品”不会直接删除物料。
8. 库存小于或等于预警值时正确提示，低库存状态随出入库变化更新。
9. 出库单 Excel 包含正确明细和签名图片，更新个人签名不影响历史单据。
10. Windows、Web、KP、安卓和手机浏览器的权限、数据与业务规则一致；手机能够拍照并上传多张入库清单。
