# UI 检查器

本批用于登录与安全页；不宣称自动判断美观，也不宣称覆盖全部页面。

运行 `python ci/lint_ui.py`，使用固定 Flutter 工具链，默认输出 `output/ui-lint/report.json`。失败返回非零。CI静态门禁检查已取消的多因素界面残留，完整Flutter测试自动运行 `app/test/ui_lint_test.dart`；发行前运行完整检查器。

动态规则读取真实 Flutter RenderBox：可见控件点击区至少44×44、独立控件不重叠、相邻操作控件至少8px间距、布局无溢出异常。当前覆盖账号、网络入口、新建用户和白名单编辑，420/900/1440三宽度、100%/125%字体、首屏及滚动状态；滚动边缘被裁切项在完整进入可视区域时检查。输入框内部按钮不算独立控件相撞。自检夹具故意制造小控件、重叠和零间距，验证规则确实报错。

这是几何和产品规则门禁。颜色对比、语义顺序、复杂地图、真实系统键盘/多DPI、所有交互状态仍需人工/真机验收，不能把检查通过当作全产品UI验收。新页面应加入测试矩阵而非扩大全局豁免。

安全表单使用独立 `SecurityTheme`：14px正文、52px输入框、44px按钮，分组卡片20px内边距、组间24px；工程数据表仍使用原紧凑密度。多因素绑定、动态码、恢复码和重置入口从产品UI移除。旧服务返回强制旧认证标记时阻止进入业务页并提示升级服务，不能静默绕过服务端认证；不清空已有身份数据库。
