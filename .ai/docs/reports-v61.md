# 报表与总览显示 v61

用户要求全部业务报表统一美化、表头和数据居中，修复小数位设置无效，并让数据总览不用横向拖动就能显示完整数字。用户明确选择总览保持一张完整表格，窄窗口缩小字号。

## 修改范围

- `app/lib/shared/table.dart` 增加可选业务报表样式：表头和内容居中、少量列铺满可用空间、分组表头、浅灰蓝层次、细分隔线、36px行高、数字等宽及合计行强调。历史、报警、统计、能耗和结算复用；开发工程表格保留原紧凑样式和交互。
- `report_number.dart` 对SQL decimal字符串做精确十进制舍入，修正“超过15个数字就直接显示原文”的问题。`3037.000000000000`在2位小数下显示`3037.00`，0和NULL仍分别显示`0.00`与`—`。原始数值、数据库汇总和CSV原始精度保持。
- 数据总览按可用宽度分配全部指标列，长数字与两行列标题自动缩小；不拆表、不隐藏列。已有筛选、绑定、虚拟滚动和移动端站点/完整表格切换保持。极窄窗口下，选择完整表格会相应缩小文字。
- 包含[v60顶部图标兼容修订](kp-icons-v60.md)，退出、KP脚本、认证与权限保持原行为。

## 验证

Go全量测试/vet、Flutter analyze、640项测试通过，2项既有跳过。新增长小数/大整数/正负舍入、0/NULL、月报和采暖季精度切换及393/1366/1920/2560宽度下31列完整数字与无横向滚动回归。

页面测试使用正常API登录建立隔离账号，KP自带Chromium110加载HTTP父页内的真实HMI程序。日报、月报、采暖季读隔离SQL Server 2017合成记录；部分其他报表仅注入合成响应检查排版，不作为对应数据库业务验收。开发SQL容器的临时证书含负序列号，只有该隔离测试服务设置兼容环境变量，未修改产品TLS默认行为、现场数据库或用户网络配置。

最终构建、浏览器截图、CSV、安装升级保留结果与CI状态将在交付时写入本页及证据。
