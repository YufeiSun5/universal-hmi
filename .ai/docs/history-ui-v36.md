# v36 历史查询与统计表展示

产品要求见 [agent.md](../../agent.md)，当前任务见 [AI_BOARD.md](../../AI_BOARD.md)，展示合同见 [architecture.md](architecture.md#历史查询与统计展示修订2026-11-04v36)。

普通历史、小时报、日报和能耗的筛选条件直接显示在页内表格上方。修改条件后清除旧结果，显式点击查询；取消等待或修改条件会丢弃旧请求的迟到响应。短窗口保留表格空间，筛选区域可独立滚动。

小时报和日报以日期、站区、小时作为行，以测点分组列显示数据库差额或最小/最大值。能耗按整站一行，横向排列水、电、热；查询多日时每天各一行。此转换只调整展示，不求和、不改变单位、不把核查小计替代完整用量。缺数保留“—”，有效零保留0。

开发态仍可维护显示列名称、显隐和顺序。身份列置左，指标字段顺序在各组内生效；指标、单位显隐决定组名。维护状态、采样时间及核查小计默认隐藏，显式开启时仍显示原状态。CSV采用同一行列结构，展开分组表头并保留数据库小数精度。

## 原始读数与统计口径

普通历史原已支持质量1/2的非空原始采样值，并非本轮才接入原始累计热量。以《数据库最新说明_20261104.md》的31站区一次、二次累计热量快照为样本，写入隔离 SQL Server 2019 后，经历史 API 查询逐值相等，质量2保留部分缺值语义。这是公开查询链路的隔离验证，不是现场数据库连接或统计口径验收。

原始表有读数与统计测点来源、整站成员口径已确认是不同条件；统计仍使用数据库返回结果。口径待确认、成员不完整、缺边界等状态不通过界面透视表补数。

## 紧凑控件与安全页面

查询栏与数据总览筛选使用独立紧凑主题，桌面约34px，窄屏保留44px操作区；字体放大时随比例增加高度。总览筛选、搜索及按钮纵向居中。安全页面使用舒适表单主题，说明、输入与记录分隔，主操作、普通操作和停用/撤销/删除采用不同样式；长文本可换行，窄窗可滚动。白名单说明独立滚动，新增与保存操作固定可见。
