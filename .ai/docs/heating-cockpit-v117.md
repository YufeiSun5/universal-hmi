11 月 20 日数据库交接包包含 17 个整站、33 个站区。16 个已有站的整站口径各配置一个电量成员及该站全部补水分区。新北站与北站共用中节能北站表，红光美苑首站与西站共用中节能西站表。壹品桃源三期 `03-004` 的高、低区累计电量和补水累计量定义均停用，两个排行保留该站，数值随实际数据可用性显示。水量成员不全时整站水单耗留空，历史趋势继续使用 SQL 已返回的可用小计。

开发端在「运行与历史 → 驾驶舱配置 → 单耗排行配置」维护三组面积。旧配置作为水、电及可沿用原站面积的热表初值，北站、西站、国奥一二期站的热面积按实际覆盖范围填。旧 JSON 仍可导入，新的 JSON 分别记录三项面积。水电排行继续支持配置显示名。
