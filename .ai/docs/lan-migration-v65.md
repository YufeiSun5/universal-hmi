# 内网开发与完整工程迁移 v65

用户要求将软件与整个工程迁至另一台 Windows 服务器，外部数据库保持，公网 IP/端口保持并由 IT 调整映射；原账号、角色范围、设备审批、证书和 MFA 必须完整保留。用户明确授权实施，并要求提供方便操作的导入/导出。

本批为本地隔离实现与交付，不修改现场或固定18153。后端 networkaccess/identity/server 管理独立内网工程师通道；projectmigration 负责加密离线文件迁移；Flutter 增加内网开发开关；Windows 完整安装包加入图形迁移工具。分层和安全边界以[架构母本](architecture.md#内网工程师开发与完整工程迁移2026-11-10-v65)为准。

## 操作方法

1. 旧电脑和新服务器均安装 v65 完整离线包。旧机安装升级保留原工程。
2. 保存所有修改，从托盘退出本工程开发端和运行端。开始菜单“智慧供热集中监控系统 → 完整工程迁移”，选“导出完整工程”，确认工程目录，选择工程目录外的 `.hmimigrate` 文件，输入并确认迁移密码。工具停止本工程后台后导出，完成后保持停止。
3. 将迁移包复制到新服务器。打开同一迁移工具，选“导入迁移包”，确认目标工程目录、文件和密码。目标已有工程时，勾选“先完整备份，再替换”；备份目录会显示在完成结果中。导入失败不会以不完整解包替换目标。
4. 在新服务器启动本机开发端，用原账号和原密码登录；已启用 MFA 的账号继续使用原验证器。检查工程、设备审批与证书、图片和数据。新机 IP 不同时，在“网络入口”重新选择本机内网 IP，按需要勾选“允许工程师在内网 Web 开发”，保存并应用。
5. 内网浏览器访问显示的 HTTPS 地址。只有具备工程师开发权限的账号可进入开发工作台；普通账号仍使用原运行功能。IT 将原公网 IP/端口映射到新服务器，公网证书及已有客户端证书沿用。

迁移密码至少10个字符，需单独妥善保存。迁移包包含完整身份和密钥材料，应按工程备份保管。切换前旧后台保持停止，防止两个实例同时采集/运行；需要回退时先停止新后台，再启动保留的旧工程。迁移不自动安装系统服务，原有Windows服务在新机需按既有本机服务工具重新注册。支持当前Windows x64/PG18完整安装版；不转换其他PG主版本。

- Flutter analyze通过；完整测试658项通过、2项既有跳过。内网开关默认关闭、保存和错误保留草稿通过。
- Windows迁移窗口渲染检查通过；完整PG搬迁、最终构建/安装、浏览器验收和CI状态待本批收尾补录，不以单元测试代替。

v64已知Linux CI设备登记合法CSR被WAF误判的问题仍单列，本批不以LAN开发正文策略声称修复公网CSR。现场端口映射、另一台物理服务器、真实客户端及原生DPI/多屏未由本机隔离验证替代。
