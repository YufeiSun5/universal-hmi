# 庄河 GIS 飞行技术演示

独立展示组件：地球 → 中国东北 → 辽东半岛 → 庄河城区。加载后自动播放固定6秒开屏；不显示地名标题、中心地名标记或底部飞行面板。支持嵌入及全屏。镜头使用对数高度与非对称平滑速度曲线，较早到达辽东、后半段减速落定；旋转与缩放共用进度曲线，飞行期间持续把画面逆时针旋转90°，最终北向在左；UI保持正向。当前落点是城区示意坐标 122.967°E、39.681°N，尚未设置真实站址。

## 运行与嵌入

2026-10-28 最终交互：右下仅两个同风格图标，圆环为演示模式，地图为静态展示。演示模式立即从当前镜头拉远（1.4秒），然后地球变速环游约9.494秒、6秒飞入、每站浮窗3.5秒并循环；在浮窗轮播时点击演示直接结束轮播。静态展示就近进入地图，只循环站点浮窗，不返回地球，再次点击可暂停。编辑态仅保留地图复位。隐藏页面冻结时钟，减少动态时只循环浮窗。`orbital-scene.js`使用NASA LROC月球球体与生成的卫星色图/法线图，固定地球光照、日照和反光角度控制卫星渐显；`celestial.js`负责不同起点、同向掠过且随高度缩小的流星。月球为略缺的盈凸月，独立展示侧光不改变地球日照。所有资源同源离线，轨道为电影式构图而非星历。验证见[自动巡展验证](../../.ai/docs/gis-tour-verification.md)。

解压演示包，运行 `Start-GIS.exe`，浏览器打开 http://127.0.0.1:18149/ 。关闭该进程停止演示；不依赖 Python、Node、API Key 或外网。默认静态目录是程序旁的 `site/`。端口占用时可使用 `Start-GIS.exe -port 18150`。

嵌入示例：`/embed.html`，提供 960×480、640×360、360×420 容器。实际内容区减去两侧边框。

```html
<iframe src="http://127.0.0.1:18149/index.html?embed=1"
        title="庄河 GIS" style="width:100%;height:480px;border:0"
        allow="fullscreen"></iframe>
```

默认自动飞行，`&autoplay=0` 或系统减少动态偏好直接进入地图。开屏期间锁定地图输入，结束后恢复拖动缩放；切换后台暂停、返回继续。低帧率时优先保持镜头连续，实际时长可能延长。

站区使用用户提供的透明 PNG，独立 `stations.json` 按稳定 ID 配置名称、经纬度。6个当前站址均为布局示意，实时数值未绑定（显示—）。开屏约5.4秒（90%进度）的最后减速阶段，图标按90ms间隔播放560ms向上生长、轻回弹，站名延后280ms渐入；每次页面加载只播放一次，地图移动不重播。悬浮提亮并显示白色浮窗：冰蓝标题区/同款站标/细蓝边框、一次/二次侧供回水双列分组、压力独立；无关闭按钮、不点击固定；鼠标离开站标与浮窗180ms后自动关闭（可跨入浮窗阅读），Esc也可关闭，小容器限制在视口内并允许滚动。按住站区图标直接拖动，超过5px开始移动、锁定地图输入，松开按经纬度保存到当前浏览器localStorage。Esc/失焦/取消/无效落点恢复起点；不再显示坐标输入框，不是正式工程配置接口。

## 自动巡展（2026-10-28，替代下方历史开场说明）

首次加载仍从6秒飞入开始，依次展示配置站点（平移0.85秒、浮窗3.5秒），再进入演示循环；两模式行为以上述最终交互为准。点击地图、站标或按 Esc 可接管，悬停不打断轮播。编辑态自动停止并保留拖动和绑定操作，巡展不保存任何配置。

太空阶段显示NASA LROC真实月面球体及短弧轨迹、流星和环绕卫星，落地后退出。月球从地球后方或屏幕边缘自然出现；卫星仅在日照及反光角度合适时渐亮，地球阴影下隐藏。地球使用固定世界光照，月球使用独立展示侧光。均为本地装饰，不代表真实天体轨道或遥测。纹理缓存、像素比上限1.5、环游约30Hz；站点停留仅轻计时。隐藏页面冻结进度，恢复不追赶；系统减少动态时省略空间运动和太空效果，浮窗仍停留3.5秒。静态模式空站点保持地图。小窗口浮窗在导航与底部控制区之间滚动。

`tour.js`只管理展示时序，`orbital-scene.js`负责世界坐标月球/卫星及光照，`celestial.js`只绘制流星；站点、绑定、工艺跳转与宿主数据质量沿用已有公开契约。正式工程不使用演示 localStorage 作为保存接口。当前 Web/Windows 通过同一离线 GIS 资源包承载；以下 2026-10-26 的未接入说明是历史记录。验收见 [自动巡展验证](../../.ai/docs/gis-tour-verification.md)。

## 分区清晰度

| 图层 | 本地范围（经纬度矩形） | 处理 |
|---|---|---|
| 庄河及周边 | 122.45,39.42 → 123.50,40.60 | Sentinel-2 原始 10 米，XYZ 7–14 级，4,725 张 |
| 大连周边 | 121.30,38.85 → 123.65,40.60 | 同日期影像降采样，最高约 120 米/像素，5–10 级，72 张 |
| 东北亚过渡 | 108,25 → 138,55 | NASA 2004-08 原始500米D1区域裁切为2048×2048，约1.6公里/纬度像素，独立本地WebP；不能当作当前地貌 |
| 其他区域 | 全球 | NASA Blue Marble 4096×2048连续底图，地面近景自然低清；不再在区域影像铺满前淡出 |

区域边缘透明羽化；根据旋转后视野是否完全进入覆盖范围渐入，避免矩形贴片暴露。运行时增加1张不到1 MB的过渡纹理，解码RGBA约16 MiB；覆盖后跳过区域层，保留全球底图作为缺瓦片时的回退。文字读数最多10Hz，镜头仍逐帧更新。云层贴图试验已按用户反馈撤除，页面无云特效或开关。范围是演示矩形，不代表行政区边界；也不承诺覆盖整个大连行政区。全部 Sentinel 影像拍摄于 **2025-09-29**，不是实时图。原始 10 米适合城区、海岸和地形背景，不能达到亚米级建筑/设备细节；瓦片过采样不会提高原始分辨率。

`site/imagery/manifest.json` 记录六景原始数据的 ID、时刻、全景云量、URL、SHA256、处理方式和引擎版本；全景云量不等同于局部无云保证。地球使用 NASA 2004年8月合成影像，另见 `imagery/earth-source.json`，构建校验固定SHA256。东北亚过渡来源、裁切范围、输出摘要另见 `imagery/region-source.json`；海水蓝色在构建时压暗以减轻与Sentinel的色差，属于展示调色，不是新的观测信息。69 MB原始D1图只用于构建，不随演示包交付。侧光属于艺术展示，非当前太阳方位；本地Canvas星空为装饰，仅在容器变化时重绘，无常驻粒子动画。接近地面时退出球体明暗，保留卫星图可读性。许可证和归属见 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)。

## 重建

庄河近景有可关闭的动态海面：`sea.js` 在地理坐标上绘制半透明材质，双尺度流动法线、缓慢涌动、随观察角度变化的反光与岸边渐隐，保留原始影像水色。抵达后继续动画，右上角「海面」可开关对比。约85 km开始渐入、35 km以内达到默认强度，出区域/远景不绘制；海面更新上限30 Hz，关闭、后台或系统减少动态时停止动画。此为装饰性表现，不代表实时风浪、潮汐或当日太阳方向。

`prepare_water.py` 使用同日Sentinel-2 SCL第6类水体，只保留与南侧海域连通的像元，向水内收缩并柔化岸边，非水体像元仍为零；不冒称测绘岸线。遮罩2048×1536约90 KB，程序生成512×512无缝法线约437 KB，合计约527 KB；GPU解码纹理约13 MiB（按RGBA估算，不含引擎临时开销）。来源与固定摘要见 `imagery/water-source.json`。海面资源失败时开关提示不可用，地图仍可使用。

在仓库根目录，以 Python 3.11+、Go 1.25.5 和支持 WebGL2 的浏览器验证。构建时需访问 npm、Earth Search STAC 及 Sentinel COG；下载缓存较大，预留数 GB 磁盘和内存。

```powershell
python -m venv .local/gis-build-env
.local/gis-build-env/Scripts/python -m pip install -r examples/gis-flight/requirements-build.txt
.local/gis-build-env/Scripts/python examples/gis-flight/prepare.py
go vet examples/gis-flight/server.go
go build -trimpath -o .local/gis-flight-demo/Start-GIS.exe examples/gis-flight/server.go
.local/gis-flight-demo/Start-GIS.exe
```

`prepare.py --output <目录>` 指定站点输出；`--skip-imagery` 仅刷新引擎和页面，保留既有影像清单。Cesium 1.127.0 tarball 校验 SHA512；固定 Sentinel 场景来源，下载后记录 SHA256。演示包由 `package.py` 生成，排除大体积原始 COG 缓存及任何业务凭据。

## 月球正面与远处环绕（2026-10-28）

月球使用NASA LROC月面，0°经线朝向镜头，北向朝上，灰白月海和第谷坑保持可识别；绕行不使纹理自转到背面。轨道半径19000km、显示尺寸上限和相机独立朝向仅为电影式构图，非天文模拟。卫星仍由日照、反光板角度及法线纹理共同控制，反光窗口更长。自动巡展、停止/重置及最新验证见仓库 `.ai/docs/gis-tour-verification.md`。

## 文件与产品边界

- `prepare.py`：离线资源制作；`prepare_water.py`：海面遮罩/法线；`sea.js`：可释放的海面展示；`flight.js/css/index.html`：飞行与页面；`embed.*`：容器测试。
- `server.go`：仅回环地址、只读静态演示服务。它不替代正式 Go 业务后端，不提供认证或控制接口。
- `.local/gis-flight-demo/`：缓存、构建、运行和交付产物；不进入源码。原有 HMI 18139 / KP 11005 本轮没有变更。

这是生产方向的技术验证，尚非生产交付。正式接入应由既有 Go 静态资源/权限体系托管，由 Flutter 平台适配层承载组件；站点坐标、图层配置通过明确契约传入，不能在 GIS 中复制采集、认证或控制业务。后续还需确认真实站址与覆盖边界、所需高清影像及使用条件、KP/桌面 WebGL 兼容、资源更新及回滚、目标设备性能与现场验收。当前影像不含 DEM 高程、三维建筑或真实站点数据。

运行 CSP 仅允许同源地图请求，Cesium worker/WASM 需要 blob 与 wasm-unsafe-eval。未开启普通 unsafe-eval；其依赖的可捕获 eval 能力探测可能出现在 DevTools issue 中，不影响已验证的渲染。验证记录见 [verification.json](verification.json)。

## 供热首页接入（2026-10-26）

Flutter Web 的“首页 GIS”菜单现通过平台适配 `app/lib/platform/gis_view_web.dart` 承载本组件；工艺画面与 GIS 共用 `MonitorHeader`。`?view=gis` 可直达，`?view=process` 保持工艺入口。首次进入6秒开屏，同一应用运行中再次进入直接落到地图；离开菜单销毁 iframe，不在后台保留渲染。`shell=1` 隐藏组件自己的品牌标题，保留海面/全屏和来源标注。

每次 Flutter Web 构建后执行：

```powershell
python ci/stage_gis.py --site .local/gis-flight-demo/site-lod --web .local/heating-monitor-preview/web
```

资源部署在 Web 构建的 `gis/` 子目录，通过既有 Go 静态服务读取；不依赖18149。入口用 `gis/map.html`，避免 `index.html` 被 FileServer 重定向到KP拒绝的目录地址；以宿主 `document.baseURI` 解析，也适配 `/kp/gis/map.html`。不向地图传票据或真实测点，地图仍仅有公开影像/示意站点。真实站址/指标接口、KP现场嵌套验证和原生桌面WebView仍待接入；桌面显示明确浏览器使用提示。

拖动示意坐标按浏览器来源保存，18149与18151为独立存储，不自动迁移。正式站址需要后端配置契约；切勿将示意位置当工程数据发布。
