`document_excel.go`读取原列宽、行高、字体、边框和合并区间；在同一工作表逐张复制模板块，按实际明细及长文本续行延长，移动合计/记事/签名区。模板公式不执行或复制到输出，数量、单价、金额来自已保存的业务快照并以文字保留精度。输出文件不依赖客户端模板路径。

缺失的业务字段及岗位签名保持空白。现有出库签名仅证明出库经办行为，在单独标明的经办签名区域显示，不冒充模板中的供应审核、保管、主管或领料签名。
