Universal HMI · Windows 浏览器证书

适用 Windows 10 / 11 的 Edge 和 Chrome。请以日常使用浏览器的 Windows 用户运行安装器。

安装器会在当前用户的 Windows 证书库中生成一份 P-256 客户端证书，私钥设为不可导出。每个 Windows 用户独立生成密钥，同一个安装器可分发到多台电脑。有效期为十年，管理员可以随时停用。

安装器还会信任包内经过指纹核对的网站公开证书，在当前用户的 Edge 和 Chrome 配置中为这个 HTTPS 地址添加精确匹配规则，并创建两个浏览器快捷方式。系统要求时会弹出一次管理员确认；该步骤只添加本站规则，不修改其他站点或注册表权限。已有相同规则时直接复用，不再要求确认。

安装后，保存浏览器中的工作，完全退出 Edge / Chrome 后重新打开。从开始菜单“Universal HMI 浏览器证书”进入网站，输入账号、密码和图形验证码。首次显示“设备正在审批”，管理员在本机“登录与安全”的设备审批页核对账号及 Windows 浏览器设备标识，批准后再次登录。服务端需已启用设备证书通道 mobile_enabled，现有安卓证书通道沿用此设置。

已批准的设备可以更换网络访问，账号仍只允许查看授权数据。管理员停用后，已有会话和实时数据连接都会失效。

重复安装及“检查与修复浏览器证书”复用当前设备证书。浏览器由组织管理时，组织级证书选择策略可能优先，请联系该组织管理员核对。遇到证书选择提示时，选择名称为 HMI Browser、与安装结果中设备标识一致的证书。

卸载会移除本工具生成的客户端证书及私钥、添加的服务器信任和仍与本工具记录一致的浏览器配置。安装时经过管理员配置的规则，卸载时同样需要管理员确认。重新安装后需要重新审批。先前已经存在的服务器信任会保留。

安装结果和设备标识保存在当前用户 LocalAppData\UniversalHMI\BrowserCertificates 下对应站点目录的“安装结果.txt”。只要原密钥有效，重复安装就保持同一个身份。证书丢失或过期时，管理员先停用旧设备，再卸载并重新安装。
