使用方法
1. 使用原 Windows 账号，从托盘菜单分别选择开发端和用户端“退出”；X / Alt+F4 仅收起托盘。
2. 从开始菜单 Universal HMI 运行“停止后台”，确认停止后运行 Universal-HMI-20261102-Full-v20-Setup.exe，覆盖原安装目录。
3. 安装完成后正常打开运行态或开发态。本版修复跨站引用变量在数值及管道动画中被旧站点判断阻断的问题，已有变量归属和绑定保持。新增的变量归属整理仅在开发端明确预览并保存后调整归属；安装不会自动迁移。先查看单站建议，多站共享和未引用变量不默认迁移，不复制变量。
4. 若需更新原28张工艺主图，请使用 delivery\process-navigation-v14-20261030\创建画面与绑定-主图父子导航-v14.json，先阅读同目录README。已有画面明确选择“精确更新已导入画面”，新工程才创建；只匹配313项主图所需已有变量，不新建、删除或复制工程变量。右侧补充栏及误导静态提示已移除，主图稳定ID与386条确定绑定保持。
5. 工艺包带客户端父站→子区菜单，默认跳过以保护已有菜单；创建或替换须用户明确选择并确认当前版本。客户端用父子菜单，开发端站点保持平铺。画面分组不等于变量归属迁移；实际分站仍使用明确预览/保存的归属整理功能。

点击X或Alt+F4会收起托盘，后台继续运行。Windows重启后，打开任一桌面图标即可自动恢复。

失败处理
普通启动失败会弹出原因和日志目录。既有未完成维护的 pending/failed 闭锁继续保留，不能用普通启动绕过；请先保存日志并联系维护人员，不要删除回执。
setup.log 记录启动步骤；postgres*.log* 为数据库日志；migration.log.* 为迁移日志；
server-error.log 为后端日志。请勿删除 private-settings.json、postgres-data 或 security 密钥。
这些文件包含私有凭据和数据，应备份整个project目录；备份前先停止后台。
PG端口冲突会停止启动，不会连接或修改别的数据库。

远程访问
开始菜单或桌面的远程入口只启动客户端，不启动本机PostgreSQL或后台。公网连接仅供查看，即使使用工程师或管理员账号也不能开发、配置或控制；开发与管理仅在本机进行。首次打开在连接设置中填写HTTPS地址并导入服务器公开证书；地址可以稍后填写。
本机公网HTTPS默认禁用且IP为空。证书工具、公网配置指南位于安装版本目录的REMOTE-ACCESS.txt；按指南显式配置并重启后才启用。安装不生成真实公网证书、不更改系统信任、路由或防火墙，不自动安装Windows服务。
